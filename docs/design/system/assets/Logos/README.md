# Logos

The X1 Cross-weave mark: two linked beads, the b and d stems crossing through a shared bead. Single-ink SVGs (`<img>` cannot inherit colour): `bd-beads-mark.svg` in light accent `#fa520f`, `bd-beads-mark-dark.svg` in dark accent `#faff69`, `bd-beads-mark-ink.svg` in `#1f1f1f`, `bd-beads-mark-white.svg` in `#ffffff`, `bd-beads-mark-small.svg` (stroke 4.2, for 16–20px) in `#fa520f`. App icons: `bd-beads-app-icon.svg` (white mark on `#fa520f`), `bd-beads-app-icon-dark.svg` (`#0a0a0a` mark on `#faff69`). Favicon: `favicon.svg` (the mark at stroke 4.2 in `#fa520f`, for light browser themes), `favicon-dark.svg` (the same in `#faff69`, for dark), `favicon-32.png` (PNG fallback, light) and `apple-touch-icon.png` (180×180, white mark on `#fa520f`). The single theme-aware `favicon.svg` for the app is in the brand book's Favicon section.
