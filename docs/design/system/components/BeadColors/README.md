# BeadColors

The Color catalog of the Project's Bead, to add a maker's color to the Palette (ticket 537, ADR 0072). Ticket 0745 made it wider and quieter (option B of the claude.ai canvas "Bead colour palette: search & facets", https://claude.ai/artifact/KMUgwFfKgUyZdfLWJ27eoB): the list widens the colour popover, its filters stand in a column beside the rows, and the two notes moved behind an Info button.

- **Entry**: a small `in-box` button with a chevron under the Palette grid in the colour popover, shown only when the Bead has a Color catalog and not in Edit palette. It reads "Palette {bead}", the Bead's label as everywhere else (Brand, Form factor and size, the same in every language): "Palette Miyuki Delica 11/0", «Палитра Miyuki Delica 11/0». It opens the list under the grid and a second press closes it. This is the maker's palette of the Bead, not the Project's Palette: the words say whose it is by the Bead's name after it (writing.md, The Bead's palette).
- **Info button** (Button card, Info button; ticket 0651's rule for help read once): right after the entry button while the list is open, named "About these colors". Its Tooltip holds the two notes the list used to show as `Note` blocks: colors are approximate because makers publish no hex (the dashed swatch edge), and a color that comes out the same as one in the Palette cannot be added twice. Nothing else in the list is a Note, apart from the states below.
- **Two layouts, chosen by the list's own width** (a container query on the list, not the screen): **wide** at 480px and more, **narrow** under it. The list is wide in the colour popover on a screen that holds it (ToolPill card), narrow on a phone and in the Convert image wizard's remap picker (FoundColorRow card).
- **Wide** (canvas boards "B · Picked" and "B · Nothing matches"):
  - Two columns, 14 apart: the **filter column** (`--bead-filter-column`, 200px; `surface` fill, `radius-lg`, padding 10 8 10 10, 12 between its parts) on the left, and the search, the count line and the rows on the right.
  - The rows scroll at `--bead-list-height-wide` (24rem).
- **Narrow** (canvas board "B narrow"):
  - The search field and a **Filters** button beside it (`field-height`, 1px `field-line`, `radius-md`, "Filters", the `chevron-down` / `chevron-up` of a disclosure, and while any value is on a dark count badge: `ink` fill, `canvas` text in `meta-tiny`, `radius-full`, 18px tall). It is a disclosure (`aria-expanded`), named "Filters, 1 on" while values are on. It opens the same filter column, full width, under the search; the Finish list then runs in two columns, 8 apart. It starts closed each time the list opens.
  - The rows scroll at 16rem.
- **Search**: one text field (TextField card, `search` type, no glyph), placeholder "Find a code or color". It finds a code as a part of a maker code or of a family name, or typed the way a shop writes it (ticket 0696). A partly typed shop code is a prefix (ticket 0713): `DB-04` lists DB4, DB40, DB43, DB433…, `11-4` on a TOHO 11/0 lists 4, 40, 41, 49…. The matches come in groups, each in catalog order: the exact code, then the codes it is a prefix of, then the codes the text is a part of, then the family-name matches, so `DB433` is first while it is being typed.
- **The filter column** (ticket 0713's filters, laid out anew), each part a `label` word in `muted` over its values:
  - **Color**: one swatch per color family of the Bead's Brand that has a code in the Bead's size, in the Brand's order, wrapping 6 apart (six to a line in the wide column, eight in the narrow one): `--filter-swatch` (24px; `swatch-touch-min` on a coarse pointer) square, `radius-sm`, the PaletteSwatches inset `swatch-edge`, filled with the family's own built-in color. On, it carries the Palette's selected ring (`0 0 0 2px` the column's `surface` as the gap, `0 0 0 4px ring`). Its name and count are its Tooltip and accessible name: "Blue, 307".
  - **Finish**: a list, one value a line, the shared Finishes present in the Bead's size in the shared order (Transparent, Opaque, Ceylon, Silver-lined, Luster, Matte, Rainbow, Metallic, Plated). A line is `--filter-chip-height` (28px; `swatch-touch-min` on touch) tall, padding 0 6, `radius-sm`, `hover-fill` under the pointer: a `--filter-check` (14px) box, 6 from the name, (1px `field-line`, radius 4, `canvas` fill; on: `ink` fill and border with a `canvas` check), the name in `tab` (13/18 500), and the count right-aligned in `meta-small` `muted`, tabular. On, the name is 600. Its accessible name is "Matte, 12" and the box is a picture (`aria-hidden`).
  - **Clear filters**: a `link`-style text button in `muted` under the Finish list, shown while any value is on. It turns every value off and keeps the search text.
  - Each value is a toggle button (`aria-pressed`) in a `group` named by its part's word; each group is one Tab stop (the Color swatches move with the arrows, Home and End; the Finish list with Up and Down, Home and End). Focus order: entry, Info button, search field, (narrow: Filters,) Color, Finish, Clear filters, the rows.
  - Within a part several values may be on (Blue or Green); across the parts and with the search they combine (Blue and Matte and `DB4`). Every count is live: the rows that value would show given everything else that is on. A value whose count is 0 is dimmed to `--swatch-faded-opacity` and still pressable.
  - The filters are the list's own: they reset when the list closes and when the Bead is replaced; they are not saved. Brand, Form factor and size are not filters (a layer has one Bead, ADR 0007). Discontinued codes stay shown and marked. The UI word is "filter"; "facet" appears nowhere a person sees.
- **Count line**, between the search and the rows: "codes: 64" at the left and, when there are more matches than the 60 shown, "first 60 shown" at the right, both `meta-small` `muted` (lowercase by style). It replaces the "Showing the first 60" Note.
- **Rows**: a swatch (`field-height` square, `line-strong` border, dashed while the hex is generated), the maker's code in `control`, and below it family and Finish in `meta-small` / `muted`, with "Discontinued" appended for such a code. Only the codes that exist in the Bead's size are listed; the list scrolls and shows the first 60 matches.
- **Taken**: a row whose hex the Palette already holds is `muted`, `aria-disabled`, and says "In the Palette" on the right.
- **States**, where the rows would be (in the right column when wide), as `Note` blocks because they change: "Loading the colors…" (`status`) and "The colors could not be loaded." (`alert`), each in place of the search, filters and rows; and the **empty state** (ticket 0713): the count line reads "codes: 0", then one `Note` sentence and, while any filter is on, one small `in-box` button **Clear filters** under it. The sentence names what is on: "No matte Blue codes match DB4." (several values of a part read "matte or luster"), "No matte Blue codes." with nothing typed, "No code matches DB4." with no filter. When the typed code is in the catalog but not in this Bead's size, it says which sizes have it instead: "4 exists in 15/0, 11/0, and 8/0, not in 6/0." There is no hint across catalogs: a DB code on a Miyuki Round Bead is simply not found.
- A press adds the color as an added swatch; the list stays open.
- **Foot row** (ticket 0700): under the list, in every state, the link **Wrong or missing color?** (Button card `link`, the `message` icon), at the right when wide and the left when narrow. It opens the FeedbackSheet's bead-color Report, Brand and catalog filled in and its Code from the row last focused in the list, else the active Palette color's code. The Convert image wizard's remap picker has no foot row.
- The same list, filters included, is the body of the Convert image wizard's remap picker (FoundColorRow card), where it is narrow.

Hand-written from tickets 537, 0713 and 0745; the Vue component `BeadColorList.vue` is the real thing.
