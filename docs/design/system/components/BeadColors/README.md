# BeadColors

The Color catalog of the Project's Bead, to add a maker's color to the Palette (ticket 537, ADR 0072).

- **Entry**: a small `in-box` button "Bead colors" with a chevron under the Palette grid in the colour popover, shown only when the Bead has a Color catalog and not in Edit palette. It opens the list under the grid and a second press closes it.
- **Notes** (`Note`, always visible): colors are approximate because makers publish no hex, and a color that comes out the same as one in the Palette cannot be added twice.
- **Search**: one text field finds a code as a part of a maker code or of a family name, or typed the way a shop writes it (ticket 0696). A partly typed shop code is a prefix (ticket 0713): `DB-04` lists DB4, DB40, DB43, DB433…, `11-4` on a TOHO 11/0 lists 4, 40, 41, 49…. The matches come in groups, each in catalog order: the exact code, then the codes it is a prefix of, then the codes the text is a part of, then the family-name matches, so `DB433` is first while it is being typed.
- **Filter rows** (ticket 0713), under the search, each a `label` word in `muted` over its values, 6 apart, wrapping:
  - **Color**: one swatch per color family of the Bead's Brand that has a code in the Bead's size, in the Brand's order: `--filter-swatch` (24px; `swatch-touch-min` on a coarse pointer) square, `radius-sm`, the PaletteSwatches inset `swatch-edge`, filled with the family's own built-in color. On, it carries the Palette's selected ring (`0 0 0 2px` the surface's gap, `0 0 0 4px ring`). Its name and count are its Tooltip and accessible name: "Blue, 307".
  - **Finish**: the shared Finishes present in the Bead's size, in the shared order (Transparent, Opaque, Ceylon, Silver-lined, Luster, Matte, Rainbow, Metallic, Plated), as toggle chips in the MirrorPopover card's Axes style: `--filter-chip-height` (28px; `swatch-touch-min` on touch) tall, `radius-full`, `button` fill, 1px `button-line`, the name in `meta` with the count after it in DM Mono `muted`; on: `panel` fill, `accent-strong` border, the text at 600. Tooltip and accessible name "Matte, 12".
  - Each value is a toggle button (`aria-pressed`) in a `group` named by its row's word; each row is one Tab stop (the arrows, Home and End move inside it). Focus order: search field, Color row, Finish row, list.
  - Within a row several values may be on (Blue or Green); across the rows and with the search they combine (Blue and Matte and `DB4`). Every count is live: the rows that value would show given everything else that is on. A value whose count is 0 is dimmed to `--swatch-faded-opacity` and still pressable.
  - The filters are the list's own: they reset when the list closes and when the Bead is replaced; they are not saved. Brand, Form factor and size are not filters (a layer has one Bead, ADR 0007). Discontinued codes stay shown and marked. The UI word is "filter"; "facet" appears nowhere a person sees.
- **Rows**: a swatch (`field-height` square, `line-strong` border, dashed while the hex is generated), the maker's code in `control`, and below it family and Finish in `meta` / `muted`, with "Discontinued" appended for such a code. Only the codes that exist in the Bead's size are listed; the list scrolls and shows the first 60 matches.
- **Taken**: a row whose hex the Palette already holds is `muted`, `aria-disabled`, and says "In the Palette" on the right.
- **Empty state** (ticket 0713): one `Note` sentence and, while any filter is on, one small `in-box` button **Clear filters** under it, which turns every value off and keeps the search text. The sentence names what is on: "No matte Blue codes match DB4." (several values of a row read "matte or luster"), "No matte Blue codes." with nothing typed, "No code matches DB4." with no filter. When the typed code is in the catalog but not in this Bead's size, it says which sizes have it instead: "4 exists in 15/0, 11/0, and 8/0, not in 6/0." There is no hint across catalogs: a DB code on a Miyuki Round Bead is simply not found.
- A press adds the color as an added swatch; the list stays open.
- The same list, filters included, is the body of the Convert image wizard's remap picker (FoundColorRow card).

Hand-written from ticket 537; the Vue component `BeadColorList.vue` is the real thing.
