# ZoomPill

The phone's zoom control: zoom out, the zoom level, zoom in and fit, floating in the bottom-right corner of the Pattern.

- `canvas` pill, 1px `line`, `elevation-1`; 36px buttons with 18px icons; the level in `meta`.
- Pinch zooms and two fingers pan; the pill is for fit and exact steps. On larger screens the canvas strip holds the same controls.

Hand-written from the responsive sign-off; static rendition.
