# ImportResult

The one-line result or error beside Import a file.

- Results and errors show beside the button that caused them, on one line, as DESIGN.md says: no shadow, no close; they go when the next action happens.
- Under 1024px (imports live in the Pattern sheet or the New / Import bar) the same text arrives as a Message toast above the dock.

Hand-written from the Phase A sign-off (forms, screens and states); static rendition.
