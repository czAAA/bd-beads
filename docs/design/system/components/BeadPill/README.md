# BeadPill

A read-only pill naming the open Pattern's Bead, shown in the header after "currently editing" and the Pattern summary.

- `pill` fill, `pill` type role (Inter 13/18 500), radius-full, padding 4 12, `ink` text.
- Only shown while a Pattern is open. It is not a button; changing the Bead is the Replace bead select beside it.
- The consumer provides the Bead label, e.g. "Cylinder 11/0 · 1.6 mm".

Hand-written from DESIGN.md §4.1 and §5.2; static rendition.
