# ToolTabs

The Tools group: four equal tabs (Paint, Fill, Select, Erase) over a 1px `line-strong` rule, with Remove line and Delete all underneath.

- Each tab: 18px icon above a `tab`-role label, padding 8 0 10, `muted`.
- **Active:** `accent` text and icon plus a 2px `accent` underline overlapping the rule.
- 10px below: **Remove line** (link, left) and **Delete all** (danger link, right).
- The consumer provides the active tool and handlers; the four tools are fixed.
