# NewProjectForm

The form that makes a new Project, in the left column while no Project is open.

- Takes the Toolbox's place in the left column while no Project is open (and on the phone, a full-height modal sheet from the Project panel's New Project).
- Order (ticket 0568): the title **Open Canvas** with the subtitle, one sentence in one block, "Draw anywhere on the Canvas, and set a Frame when you want a picture or a PDF." (ticket 0853), Name (optional; its placeholder is the name a Project left unnamed takes, "Project 1", then the next free number as Duplicate counts, never the Bead's name, ticket 0866; up to 40 characters, its counter from 30, ticket 0854), Maker's name (optional, placeholder "Your name"), the Layer settings (LayerSettings card, ticket 0670: Technique and its settings, Bead, Background), then the form's one primary button, Create Project, and after it, each after "or", the secondary Convert image and Pick a starter (StarterGallery card; ticket 0866). Name and Maker's name are the sections the Project panel shares, the Layer settings the section the Project and Frame panels share (ProjectPanel and Frame cards); here they apply at once, with no confirmation, and both layers of the new Project start from them. They are preset (the Background on the device's last pick) and can be changed at any time.
- **Not for the first Project (ticket 0866).** The Homepage's Make your first Project, while the library has no Project, makes one at once on this form's presets, through the same Create Project, and the editor opens on its Canvas with the Tool pill ready and no panel open, so the Canvas is the first thing seen; every choice stays in the Project panel. New Project from the Menu or the empty Canvas still opens the form.
- **No size (ticket 342).** The form has no Frame, Unit or Width & Height sections and no Estimate info popup: Create Project always opens a Canvas with no Frame, and the size is set afterwards in the Toolbox's Frame section (MirrorSizeControls card), in beads or mm.
- "or" then Convert image, always enabled. It opens the Convert image wizard (ConvertImage card, spec 0645, ticket 0646), which starts from this form's Name, Maker's name, Bead and Technique and keeps its own copy, so Cancel there leaves the form untouched. Until spec 0645 is built, a chosen picture opens a small size dialog before framing (ADR 0026): "How big is the Schema?", the beads | mm switch, Width and Height (a typed mm value rounds up to whole beads), the size in the other unit beside the switch, the slow-framing heads-up, Cancel and "Frame the picture".
- Convert image warnings (slow framing) use the warning icon; its errors (HEIC, SVG, too big, too many pixels, unreadable, wrong format) use the error style, with the app's existing sentences.

Hand-written from the Phase A sign-off (forms, screens and states) and the v16 sign-off; static rendition.
