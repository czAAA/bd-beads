# PrintWide

A framed Schema wider than tall keeps the portrait A4 layout: a shorter picture on page 1, the same full-page chart parts after it.

- The PDF is always portrait. On page 1 the board stays at the full page width and loses height, which leaves more room for Beads needed.
- A 240 × 60 Schema: page 1, then parts of about 56 beads across (`print-chart-cell`, 3 mm) and 60 down, the last holding what remains; a leftover part may share a sheet.
