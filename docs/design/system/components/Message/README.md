# Message

A notice or toast: "couldn't save", import results and errors, confirmations of an action. (Derived in DESIGN.md.)

- **Shape:** `panel` fill (light) / `elevated` (dark), 1px `panel-line` (light) / `line-strong` (dark), radius-lg, `elevation-3`, padding 12 16, max width 420. A 3px left edge in the tone: `accent` for info and success, `warning`, or `danger`. The edge and the icon are always the one tone color, in every theme (ticket 0855). The `danger` tone is `--message-danger`: `danger` red in light and high contrast, gold (`accent-strong`) in dark.
- **Content:** a 16px icon in the tone color, the text (`body`), optional text-button actions, and a 28px close ×.
- **Placement:** library-wide notices use the notice row under the header, full width, at elevation 0. A notice whose line names a Project ("“Scarf” didn't open last time.", `warning`, closable, ticket 0716) puts its two `in-box` actions, Remove and Export, on their own line under the text, so a long name keeps its room on a phone. Short-lived results show as a toast at the top-right of the canvas box, 16px in and under the strip (under the save ring while it shows, 8px below it; SaveReminder card, ticket 0796), stacking downward on the toast layer, and go after 5s unless hovered or focused. Errors stay until closed.
- **Open in another tab** (notice, `warning`, not closable; ticket 0834): while the open Project is open in another tab, which opened it first. English: "This Project is open in another tab. Changes made here aren't saved while it is open there." It goes by itself once that tab opens another Project or closes.
- Import results and errors show beside the header button that caused them as a compact one-line message (no shadow, no close).
- **Color removed** (toast, info tone, with Undo): after an added swatch is removed from the Palette. English: "Color removed from the Palette." with the text action "Undo". Russian: «Цвет удалён из палитры.» with «Отменить». The action is a text button (`control`, `ink`, underlined) before the close ×. Like other toasts it goes after 5s unless hovered or focused; Undo puts the swatch back. Russian reviewed in ticket 283 (matches Delete wording).
- **Fill refused** (toast, info tone, no action; ticket 0715): after a Fill tool press on the Canvas that Fill reach refuses. Open space: "Nothing encloses this spot. Select an area to fill it." Over the Fill cap: "Too big to fill. Zoom in, or select an area." One toast for both (showing it again replaces it); it goes after 5s like other toasts. The other languages are in `writing.md` (Fill reach copy).

- **Kept** (toast, success, no action; ticket 0839): after Keep Projects (the Keep note or the Menu row "Keep Projects on this device"), when the browser agreed. English: "This browser will keep your Projects." It goes after 5s like other toasts.
- **Not kept** (toast, `warning`, stays until closed; ticket 0839): the same press when the browser declined. English: "The browser didn't agree to keep Projects. Save a Project file of each one you care about." with the text action "Save Project file", which saves the open Project's file as the Project panel's row does (none with no Project open). One toast for both: showing either replaces the other. The other languages are in `writing.md` (Keep Projects copy).
