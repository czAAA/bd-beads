# MirrorSizeControls

The Mirror and Size disclosure rows opened in place, and the Estimated size warning.

- A DisclosureRow opens in place, pushing what follows down; the chevron turns up. Each control is one line: Steppers for the axes, a Switch for Copy mode, two buttons for Mirror current.
- Size: the estimate (with its info tooltip) first, then Columns and Rows, each with its own Change from (end / start). The Peyote and brick-stitch hint about pairs of rows shows under Rows when it applies.
- While Row progress is on, the size steppers are locked and "Turn off Row progress to change the size" is written under them.
- The estimate warning is the Tooltip at a 280px measure; on touch it opens on tap.

Hand-written from the Phase A sign-off (forms, screens and states); static rendition.
