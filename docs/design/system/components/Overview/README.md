# Overview

The one page outside the editor, at `/overview`: the front door for a new visitor (empty Pattern library), reachable from the header menu, drawn lighter and more by hand than the editor.

- **How it sits with the first principle:** the editor stays an editor; this is a single introductory page with the same tokens and voice, three Overview-only type styles (`tagline`, `serif-heading`, `note`), no marketing phrases and no screenshots. It is the only screen that scrolls as a page.
- **Header:** as in the editor: the X1 mark and "bd-beads", the `menu` button (HeaderMenu), EN / RU, the theme control (one icon opening the four-way sheet on the phone). No Keyboard shortcuts.
- **Hero, centred:** the mark and wordmark; the slogan **Draw. Joy. Weave.** / «Рисуйте. Наслаждайтесь. Создавайте.» in `tagline` (40px phone, 58px from 744, 60px from 1024, 70px at 24″; Russian 20% smaller), the last word in `accent-strong`, with the note "you" / «вы» on its first word, always shown, in the same font and style as "you are here" / «вы здесь»; **save. count. export** / «сохраним. посчитаем. экспортируем» in `mono` 15px `muted`, with the note "on us" / «это мы», always shown, in the same style; **Make your first Pattern** (primary, starts the Tour) and **Open the editor**, with "eleven small steps" and a thin arrow beside them from 1024 (first-time visitors only, like "you'll make this" below); the Tour Pattern lying across as a band on its `board` (no ruler), and "you'll make this" centred under it in `note-gold`.
- **With Patterns saved:** only **Open the editor** (primary), "Patterns saved: {n}" in `meta-small`, no notes.
- **What's inside:** `serif-heading`, no label above it. A carousel of the seven features (Techniques, Pattern editing, Convert image, Row progress, Beads needed, Exports, Saved Patterns; Mirror not listed), each with an example drawn as beads. From 1024: the list left (selected item on `panel` with a 2px `accent` bar and its line), the example right, ‹ › and "3 / 7" top-right; a `tablist`, arrows move. Below 1024: swipe cards with dots and ‹ ›. On a MacBook Air the whole carousel is above the fold.
- **Examples:** hearts in loom, peyote and brick stitch; a poppy with Paint active and a Selection frame; a picture beside its 6-colour beaded version; rows done faded with the current row marked and a mini Progress bar; Beads needed for the Tour Pattern; a PDF page with the technique word filling its width (uniform scale, never stretched); the Saved Patterns gallery.
- **Coffee tile:** as wide as the main column (the same edges as "What's inside" and the plan tiles), stacked and centred: a beaded cup with three beads of steam, "Made by one person" in `serif-heading` 30px, one line of text with no width cap (one line where it fits, two on a tablet or a narrow laptop, more only on a phone), **Buy me a coffee** (secondary) to the maker's own page. No donation-service name, logo or colours.
- **Three ways to use it:** No account (works now, 2px `ink` edge, "you are here" note, primary **Open the editor**), Free account and Pro (switched off: disabled buttons, "coming later", the reason written once). Each tile: a strand of one to three beads, the name in `serif-heading`, price and `meta`, one line, the button, then "everything in …, plus" and checks. Plan contents are placeholders; no integration.
- **The drawn layer:** notes in `note` (`muted`, or `accent-strong` for "you" / "on us") with 1.25px hand-drawn arrows; bead drawings (flower, heart, bee, spool, leaf, rhombus, sparkles) in Palette colours beside the main column, large ones at 16% opacity with a clear margin from text and controls; three to five X1 marks per section at 8% `accent`, as on the PDF exports. Each drawing sits a fixed gap (24-48px) outside the main column's edge at every screen band, measured from the column, not the page, so it stays close to the content as the page widens; where a band has no room beside the column (phone, tablet, the low end of laptop) the small ones tuck into the gutter or into blank space beside the hero's text. They thin out per band, counting from the laptop and desktop amount (from 1440): about two thirds from 744 to 1439, about one third on a phone. The header logo is not part of the layer. All `aria-hidden`, behind content, never touching text.
- **Layout:** container 1080px (1200px at 24″), padding 16 / 24 / 32 / 40. No footer.
- Copy in English and Russian: the Writing section, "Copy added in v15".

Hand-written from the v15 sign-off; the preview is the signed page laid out with container queries at each tier's width.
