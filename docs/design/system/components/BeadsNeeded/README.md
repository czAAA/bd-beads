# BeadsNeeded

An expandable panel listing how many beads of each color the Pattern needs, with the total in its title.

- **Expandable panel template:** a box that shows a fixed-height summary and grows downward when expanded. Header 28px tall, 8px to the body: title (`control`) with an optional muted suffix in body weight, optional meta on the right, then the Expand button (↓; ↑ when expanded, with an "esc" kbd hint). Escape or ↑ collapses it.
- Box: elevation 1, padding 14 20 16.
- Body: up to 3 color rows while collapsed (32px each, 96px), each with a 1px `line-soft` rule above: a 12px swatch (`radius-2xs`, inset `swatch-edge`), the color name (`body`, `body` color) and the count (`meta`, `ink`, right-aligned). Expanded, every color shows.
- Each row shows the count and, after it, the weight in `meta` `muted` ("2.5 g"): count ÷ the Bead's beads per gram (a catalog field), rounded up to 0.1 g, so every weight has one decimal ("0.5 g" for 38 Cubes, never "0.41 g"; a single bead "0.1 g"). The title adds the total weight, rounded up the same way ("· 1 200 · ≈ 13.0 g"). An unknown Bead shows no grams.
- **The Bead to buy (ticket 0974):** the first line of the body, under the header, in `meta` `muted`, names the Frame's Bead as the Layer settings summary does ("TOHO Cube 1.5mm"), with or without painted beads; none with no Frame.
- **Palette colors (ticket 0974):** when any row's color has no catalog code (a Palette or Custom color), one line under the rows, in `meta` `muted`, says "Palette colors, not bead codes". The reason is behind the header's Info button, after the weight's line: "Colors without a code are the Palette's own, picked on screen rather than from the Bead's color catalog, so no bead is named for them. A color picked from the color catalog shows its code here." The button is then named "About these counts" (and shows with an unknown Bead too); while every color has its code there is no line and the button explains the weight only.
- Numbers group thousands with a no-break space: "1 200".
- **One face of a Kaleidocycle (ticket 0876):** its counts are one face of four, so under the rows, in `meta` `muted`, "These counts are one face of 4. Whole piece: 3 612 · 15/0: 120", and an Info button named "What the counts cover": the piece's faces, a Frame for each other face, and that the whole piece also counts the beads that join the triangles. The whole piece is every face beaded like this one plus its joins' beads of the face's Bead; its 15/0s are another bead size, so they get their own count after a `·`, in the "Label: number" form.
- **The whole piece's lines (ticket 0877):** under that line, 4px down, one line each, in `meta` `muted`, the label left and the count right (tabular figures, grouped as the rows are): Triangles, Edge Beads, Hinge Beads, then the two 15/0 lines, each named with its size after a `·`: "Triangle Tips · 15/0", "Hinge Pins · 15/0". At Part size 9: 3 240, 288, 84, 72, 48 (the Kali Primer's pictures counted). No swatch and no weight: the join beads' colours are the beader's choice, and a 15/0 isn't the Frame's Bead.
- **A Star, front and back (ticket 0875):** its back is beaded as the face's mirror, so every count is the whole star (each face bead twice, the five tip beads once), and under the rows, in `meta` `muted`, "These counts are the whole star, front and back." No Info button.
- **Counts the Frame only (v16):** beads outside the Frame are not counted. With no Frame the panel keeps its header and says "Set Frame to count beads." (EmptyPanels).

**In the Frame panel (tickets 0555, 0852, 0932):** Beads needed is the Frame panel's section right under its name and the export section (always open, ticket 1121), above size, so its total and first rows are in view as the panel opens at every width; the total also stands on the panel's title line and in the Canvas strip's Frame button Tooltip ("Open Beads needed (299 · ≈ 3.3 g), the Frame’s size, Rotate and Remove.", the plain "Open the Frame’s size, Rotate and Remove." while nothing is painted), all one count; not an expandable box: the total in its PanelSection header, kept there while open, `panel-row` rows (14px swatch, the color label, count, grams), five shown, then "Show all colors ({n})" opens the rest in place, in `accent-2` while they are hidden (ticket 1121; MenuPanel card).
- **The weight's Info button (ticket 0852):** right after the header's label, shown while there is a weight, named "How the weight is worked out". Its Tooltip says the facts only, no advice: "This is bead count × about 0.0108 g per bead. The average is from the maker's beads per kilogram, or from seller listings where the maker gives none. Real beads vary by color and finish." The average is written with the language's decimal sign ("около 0,0108 г"). The beads per kg are TOHO's and Miyuki's published figures (TOHO's Beads Per Kg Chart, Miyuki's Size and Bead Count Data); TOHO Cube 1.5mm, which TOHO doesn't list, keeps seller listings' figure. It counts the Frame only, so it is absent with no Frame. In Convert image's Review (ticket 0759) the same section opens closed every time and keeps its state nowhere, for the Project about to be created.

**The color label (ticket 0760):** a catalog color reads "49 Opaque Black" in `control`, the code and the catalog's name for it, in the one label the Palette, the colour popover and FoundColorRow use too; its hex is only in a Tooltip, on hover and long-press. A Palette color with no code reads as its Palette name ("Red"), a Custom color as its hex in DM Mono with no Tooltip. The label wraps rather than being cut.
