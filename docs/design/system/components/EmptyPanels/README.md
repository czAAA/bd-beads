# EmptyPanels

Beads needed and Saved Patterns with nothing in them.

- An empty panel keeps its header and shows one 13px `muted` line, the app's existing sentences. No expand button while there is nothing to expand.
- **No Frame (v16):** with a Pattern open and no Frame set, Beads needed says "Set Frame to count beads." "Nothing painted yet" is for a Frame with no beads in it.

Hand-written from the Phase A sign-off (forms, screens and states); static rendition.
