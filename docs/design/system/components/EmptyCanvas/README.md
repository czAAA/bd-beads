# EmptyCanvas

What the canvas box shows while no Pattern is open.

- The canvas box keeps its frame; the drawing area shows an empty board (the `board` with `bead-empty` beads, no curve or word), "No Pattern open yet" in `control` and one line on what to do.
- The line under it is new copy, proposed. The Progress bar is hidden until a Pattern is open.

Hand-written from the Phase A sign-off (forms, screens and states); static rendition.
