# PaletteSwatches

The Colors group: the Pattern's Palette as an 8-column grid of square swatches that grows by rows from 12 to 40, then Custom.

- **Grid:** 8 columns, gap 6, square swatches, radius-sm, inset 1px `swatch-edge` so ivory and black do not vanish.
- **Contents:** the 12 built-in swatches first, then every Custom color that joined the Palette by painting a cell, in the order it was added. Up to 28 can be added, so the group holds 12 to 40 swatches.
- **Grows by rows beyond twelve:** the 12 built-in swatches take a row and a half; added swatches 13 to 16 complete the second row, and each further eight add a row, up to five full rows at 40. The grid wraps; it never clips and never scrolls sideways. The Toolbox grows with it.
- **Added swatches** look and behave exactly like built-in ones: the same size, the same inset edge, the same selected ring, the same focus ring.
- **Selected:** `0 0 0 2px panel, 0 0 0 4px ring`. **Focus:** 2px `focus-ring`, 2px away (the app now matches; it was 4px).
- **Recent** (ticket 0865): a swatch whose color is one of the Tool pill's three recents stays in its own slot and carries a thin ring, `0 0 0 2px panel, 0 0 0 3px field-line` (the same gap as Selected, 1px, in `field-line`), so the color just used is found where it was and the grid never shifts as colors are used. Selected wins over Recent (the chosen color is never one of the recents anyway).
- **Touch** (`pointer: coarse`): `repeat(auto-fill, minmax(36px, 1fr))` instead of 8 columns, the same 6px gap, so swatches stay at least 36px.
- **In the wide colour popover** (ticket 0745, ToolPill card): `repeat(auto-fill, minmax(var(--palette-swatch-min), 1fr))` instead of 8 columns (`--palette-swatch-min`, 27px, the swatch's size at 8 columns in the 288px popover), the same 6px gap, so the swatches keep their size and the grid takes fewer rows. The touch rule above still wins on a coarse pointer.
- **One Swatch (ticket 333; `AppSwatch` in the app):** the Palette, and the Canvas color popover use the same chip. It takes a color, `selected`, `recent`, an optional key chip, its Swatch letter while Letters is on and, in Edit Palette, a ×. The ring's gap is the surface it sits on (`panel` in the Toolbox, `overlay-fill` in a popover).
- **Tooltip:** the name "Color" (Russian «Цвет»), the hex as the body (a swatch picked from the Bead's Color catalog has its **color label** as the name instead, "49 Opaque Black", and the hex stays the body) and the key chip where there is one (see the Menu card). Only the first seven Palette swatches have a key (Shift+4 to 9, Shift+0), a recent one too, so a slot's key never changes as colors are used (ticket 0865); Shift+1 to 3 are the recents (see the ToolPill card); added swatches and Canvas colors show just the name and hex.
- **Accessible names:** every swatch has one. A built-in swatch is "Color 1, black"; an added swatch is named by its hex ("#6b3fa0"); a swatch with a catalog code is named by its **color label** (ticket 0760): the code and the catalog's name for it, "49 Opaque Black" (the Finish then the color family in English, "Black · Opaque" in the other languages), or just the code until the catalog has loaded. One label is used for every real catalog color in the app (BeadsNeeded, FoundColorRow, the colour popover); a Custom color, which has no name, keeps its hex.
- **Swatch letters (ticket 1092):** while the Palette's **Letters** switch is on (ToolPill card), every swatch shows its Swatch letter centered on it, in `small` (Inter 500, 12px), `swatch-mark-dark` or `swatch-mark-light` whichever reads on that swatch's hex, as a bead's letter is. The swatch's name then ends with it: "Color 3, red, letter C" («Цвет 3, красный, буква C»). The same switch letters every bead on the Canvas; the Frame's beads follow the Frame's own switch. Off by default, saved with the Project.
- **Removing an added swatch (ticket 0531, replaces tickets 228 and 304's hover ×):** at rest no swatch shows a ×; the only ways to remove are **Edit Palette** (below) and Delete or Backspace on a focused added swatch (`aria-keyshortcuts="Delete Backspace"` on added swatches only; they act on the swatch, not on the Erase tool or the Selection, and work on any focused added swatch, selected or not).
  - **Confirmation (ticket 304, unchanged):** every route opens a confirmation in the ConfirmDialogs style, and nothing is removed until Confirm. English: title "Remove color?", message "{hex} will leave the Palette.", buttons "Cancel" and "Remove". Russian: «Убрать цвет?», «Цвет {hex} уйдёт из палитры.», «Отмена» и «Убрать». When beads are painted in the color (ticket 1124) the message names them, as they leave with it: "The {count} beads painted in it go too." (one: "The 1 bead painted in it goes too."), Russian «{count} бисеринки этого цвета тоже исчезнут.»; a route that removes at once (a Bead colors row) asks first then. On Remove the color and every bead in it leave both layers, the Frame's Folded beads too, in one Undo step, so no bead is left with a color that has no Swatch letter (exports printed "?"); the toast's Undo puts the beads back where their places are still empty. Cancel, Escape and the backdrop leave the swatch alone.
  - After Confirm the grid closes the gap and a toast offers Undo (see the Message card). Undo puts the swatch back in its place, selected again if it was selected.
- **Edit Palette (ticket 0531):** a mode of the Palette in the colour popover (ToolPill card holds the pencil that enters it). While it lasts:
  - **Added swatches** show a **×** centered on the swatch, always, not only on hover: the `close` glyph at `--swatch-edit-remove-size` (16px, about 60% of a 27px swatch) with `--swatch-edit-remove-stroke` (2.5), round-ended, drawn `swatch-mark-dark` or `swatch-mark-light` whichever reads on that swatch's hex, with the same thin `swatch-mark-halo` of the other color. No background, border or badge: just the glyph, appearing with a fade of `duration-fast`, none under reduced motion. The whole swatch is the hit area (the 36px floor on touch), so a click, tap, Enter or Space anywhere on it asks to remove it with the confirmation above; Delete and Backspace do too. The ×  is a picture, not a second button or Tab stop. The swatch's name is "Remove #6b3fa0 from the Palette" («Убрать #6b3fa0 из палитры») instead of the hex alone. Choosing a color does not happen in this mode and the popover stays open.
  - **Every swatch has its letter on a button under it** (ticket 1092), default colors too: the swatch and its letter button are two targets, one above the other, 2px apart, never overlapping, so each is pressed without care. The button is the swatch's width and `--swatch-letter-height` (28px) tall, 36px on touch; `elevated` fill, 1px `field-line`, `radius-sm`, the letter in `small` `ink`; the border turns `ink` on hover and focus. The grid's rows stand 10px apart in the mode (6px otherwise), so a letter button is not pressed for the swatch under it. The swatch shows only its ×; the letter is on the button. Named "{letter}, change the letter of {name}".
    - **A press turns the button into a field** of the same box, with the letter selected. One or two of A to Z are kept as they are typed, in upper case; anything else (a digit, as the Word chart writes a count before a letter) is not taken. Enter, or leaving the field, saves; Escape leaves the letter as it was and keeps the mode; nothing typed changes nothing. A press outside saves and goes on to what was pressed, so the next letter opens with one press.
    - **Two colors never share a letter.** A letter another color has is traded: that color takes this one's. A line under the grid (`Note`, `role="status"`) says which color got which: "Red is now A. Black had it and is now C." One Undo step puts both back.
    - **Keyboard:** the letter buttons are one Tab stop after the swatches, the arrows moving between them.
  - **Built-in swatches** are faded to `--swatch-faded-opacity` (0.35), keep their place and can still be focused and dragged. A Tooltip (AppTooltip, on hover and focus) says "Default colors can't be removed" («Стандартные цвета убрать нельзя»); the swatch is `aria-disabled="true"` and the Tooltip text is its description.
  - **Pick color from canvas** and **Custom color** are disabled (the disabled look in forms-and-states.md) and take no press.
  - **Reorder:** dragging a swatch to another slot (and Alt+Left/Right) works as in normal mode; a press that moves past the drag threshold never counts as a click, so it never asks to remove.
  - **Exit:** the check that the pencil became (ToolPill card), Escape (leaves the mode only; the popover stays), or closing the popover. The popover always opens in normal mode.
  - **Remove all custom colors:** see the ToolPill card (bin after the word "Palette"). Confirmation English: title "Remove all custom colors?", message "{count} colors will leave the Palette." (one: "1 color will leave…"), then, when beads are painted in them, "The {count} beads painted in them go too." (ticket 1124), buttons "Cancel" and "Remove all". Russian: «Убрать все свои цвета?», «Цвета ({count}) уйдут из палитры.», «{count} бисеринки этих цветов тоже исчезнут.», «Отмена» и «Убрать все». Cancel is the focused button. One toast offers a single Undo that puts every removed color back in its slot.
- **No cap (ticket 0525):** any number of Custom colors can be added; the grid grows by rows and the popover or sheet scrolls. The Palette belongs to its Project, so it is the same on every device.
- **Pick color from canvas (tickets 398, 403):** the grid's last tile, a swatch's size (the same 36px floor on touch) holding the 22px `eyedropper` icon, with the Toolbox button's look and `aria-pressed` while it is on. It is not a slot: it isn't dragged and has no Shift+key. While it is on the canvas pointer is the eyedropper, hot spot on its tip, in place of the bead marker and paint preview; a chip below and right of the tip (flipping at the canvas edge by its own width) names the color of the bead under it, and none over an empty cell or for a finger: a color the Palette holds with a catalog code by its code and color name, as the Palette's Tooltip names it ("49 Opaque Black"; the code alone until the Bead's catalog has loaded), any other color by its hex, on one line. No Tool pill tile is lit while it waits, Paint included (ToolPill card). **From the Reference image (ticket 1119):** a press on a position with no bead, where the picture is shown, takes the picture's color under that bead's centre as the nearest code of the Palette's Bead, which joins the Palette with its code; a bead's own color always wins, and a hidden picture gives nothing. The chip shows nothing there. **On touch**, which has no pointer to show, arming it shows the info toast "Tap a bead to use its color." («Нажмите на бисеринку, чтобы взять её цвет.»), and while the picture is shown "Tap a bead or the reference image to use its color." («Нажмите на бисеринку или на подложку, чтобы взять цвет.»), gone when it ends. Its Tooltip line is "Use a color from a bead on the Canvas, or the nearest bead color from the reference image. It joins the Palette." («Возьмите цвет бисеринки на холсте или ближайший цвет бисера с подложки. Он попадёт в палитру.»): the Palette has no cap, so no "if a slot is free" (ticket 0845). Esc or choosing a tool ends it.
- **Tools sit on this grid (v18):** the Tools group above uses the same 8 columns, 6px gap and square size, so tool tiles and swatches line up (ToolTabs card).
- 12px below: the **Custom** button (a 14px hatched square in `muted`, always, never a fill of the chosen colour, then the label; the hatch stands for "pick any color") Unchanged by the longer grid.
- The swatch colors are the Pattern's bead colors (user data), never brand colors. The consumer provides them and the selected index.

Hand-written from DESIGN.md §5.5 and the v16 Palette change; static rendition. The preview shows 12, 16 and 40 swatches at the Toolbox's 264px content width, then the touch layout, with an Edit Palette row (centered × on added swatches, faded built-in ones). The first 12 are the built-in Palette colors (see the Glossary card); the added ones are sample bead colors.

- **Approximate Bead colors** (DS-2, ticket 0905; ConvertImage card): in the Convert image Change picker's grid, a Bead color whose swatch is approximate carries the 1px dashed `field-line` outline 1px out; a measured one is plain. The selected `ring` draws outside it.

## Sections and Add another color (ticket 1224, approved 2026-11-24, in the app since ticket 1226)

ADR 0103: the Palette is the Project's own, in sections per Color catalog. Option B "Beside the Palette" of the 1224 design canvas (local, owner's Mac). Where this part and the rules above disagree, this part wins: ticket 1226 built it. Built as drawn, with these readings: the Convert image picker (a row, not the pill's popover) keeps today's Custom color and Add {bead} colors entries until it is designed; the Bead colors list's rows say "In the Palette" with a check where a code is held, the old "Same color" row being gone; and the nudge Note names the clash by its section, and by its code where it has one.

- **Sections, stacked.** The Palette is one section per Color catalog (TOHO, Miyuki Delica, Miyuki Round) plus **Custom colors**, each shown only once it holds a color, top to bottom in the Project's order. A section is a label line (the catalog's name in `meta-small` `muted`; "Custom colors" «Свои цвета»; catalog names stay Latin in every language) over its swatches in the grid above (8 columns, 6px; the touch rule; it wraps, never scrolls sideways). The top stays as today: the "Palette" label row with Letters, then the first section, a new Project's first layer's Bead's default colors, recents ringed in their slots. Sections stand `space-12` apart. Shift+4…0 count the slots across sections in order.
- **The popover** is `--palette-popover-width` (23rem) wide, so the head holds a named code beside its hex (below). The ToolPill card's wide popover (`--popover-width-wide`) is retired with the Bead colors entry: the Palette popover never widens.
- **Naming a code.** The head and a swatch's Tooltip read the color family and the code alone, "Red · DB723" («Красный · DB723»), the hex below (owner, 2026-11-27, ticket 1261; it was "Red · Miyuki Delica code DB723"); where the family isn't known, the code alone. A list row's first line still names the catalog (owner, 2026-11-24: a bare "1" confuses a newcomer), "TOHO code 1" («TOHO, код 1»), "Miyuki Delica code DB723". A Custom color has no code and keeps its hex.
- **One Add another color.** Under the last section: a full-width `in-box` button with the `plus` icon, "Add another color" («Добавить ещё цвет»), and **Pick color from canvas** beside it as a square icon button of the same height (it adds to Custom colors; behaviour as above). They replace the grid's Pick tile, the Custom color tile (ColorPickers card) and the "Add {bead} colors" entry (BeadColors card). One action, three former triggers: no new code path.
- **The Add another color popover** opens **beside** the Palette popover, to its left, `--add-color-popover-width` (35.5rem), the same popover look (`overlay-fill`, `radius-xl`, `elevation-3`), its bottom level with the Palette's, `space-12` between them; it never covers the Palette, so each color added is seen landing in its section. Where the screen has no room on the left it goes to the right; a phone keeps today's stacked layout (not designed further). Its head: a SegmentedControl **Bead colors | Custom color** («Цвета бисера | Свой цвет») filling the row, then Close. Escape or Close shuts it alone; closing the Palette shuts both.
  - **Bead colors** (opens here): the **Bead chooser**, three PanelPickers Brand / Type / Size («Бренд / Тип / Размер») in one row as in the New Project form, listing every onboarded Bead and starting on the first layer's Bead; then that Bead's list (BeadColors card, wide layout: filters column, search, count line, rows, foot row). Changing the Bead keeps the popover's size.
  - **Custom color**: the ColorPickers wheel, slider, preview with its + and hex field, centered.
  - Each color added joins its own section (a catalog code its catalog's, a wheel color Custom colors), a new section appearing at the bottom; the popover stays open for the next.
- **A hex clash is told once.** A code whose hex another section holds is added nudged one step (ADR 0103), and a `Note` (`role="status"`) under the segmented control says so: "Already in TOHO as code 341, so it's added a shade apart." («Такой цвет уже есть: TOHO, код 341. Поэтому он добавлен на тон иначе.»); for a Custom color "Already in Custom colors, so it's added a shade apart." («Такой цвет уже есть в своих цветах, поэтому он добавлен на тон иначе.»). It goes with the next add or when the popover closes. Such a row is no longer "Same color": it can be added.
- **Edit palette, with sections.**
  - **Every swatch is removable** (owner, 2026-11-24): default colors carry the × like any other and ask the same confirmation; the faded look and "Default colors can't be removed" go.
  - **A section's label line is its drag handle**: the whole line, `cursor: grab`, named "Move section {section}" («Переставить раздел {section}»), Alt+Up/Down by keyboard. While dragged the section lifts (`elevation-2`) and a 2px `focus-ring` line shows where it lands between sections. Swatches keep their own drag, within their section: a swatch never changes section.
  - **Remove section** at the line's right: an IconButton with `delete`, named "Remove section {section}" («Убрать раздел {section}»), on every section. It asks in the confirmation above: title "Remove the {section} colors?" («Убрать цвета {section}?»; Custom colors keeps "Remove all custom colors?"), message "{count} colors will leave the Palette.", the beads line when beads are painted in them, buttons "Cancel" and "Remove all"; one Undo puts the section, its colors and its beads back. The last section can be removed too; the Palette is then empty and Add another color is the way back.
  - Add another color and Pick color from canvas are disabled.
- **States drawn on the canvas:** default, hover, Bead colors open, Custom color open, nudged, edit, dragging a section, the confirmation, a new Project (one section), long (a 40-swatch section, Miyuki Round 15/0, Russian). desktop 1710×907 and iPad 1366×1024 landscape, light, dark and contrast.
