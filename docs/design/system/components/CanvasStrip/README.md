# CanvasStrip

The header strip at the top of the canvas box, one component on the editor and on the Overview: three slots: the panels (Menu, in the editor Project and Frame) aligned left, the Brand centred, and the tools (Rotate canvas, Rulers, Undo, Redo) with the zoom aligned right. Its height is its tallest item plus 1px above and 1px below (ticket 544): the Menu button (34px) plus 2px with a mouse, the 44px touch targets plus 2px (46px) on a coarse pointer; `--strip-height` (controls.css) is the same rule for the Overview. It has a 1px `box-line`-tint edge on its left, right and bottom, and its top corners take the canvas box's radius (`radius-lg`, `--canvas-box-radius`). It names no Project (tickets 425, 431, 0443, 0473, 0540, 0543, ADR 0055, ADR 0073).

- The canvas box: `box` fill, 1px `box-line`, radius-lg, `elevation-2` (light only), overflow hidden; it takes all the width right of the left column.
- Strip: padding 0 10 0 16, gap 8, bottom divider `box-muted` at 22%. Three slots in a grid (`1fr auto 1fr`): Menu, Project and Frame on the left, the Brand in the middle, the canvas controls on the right.
- **No title, size line, printed-size estimate, grid icon or keyboard-focus hint** (ticket 425 removed them; before it the strip read "Canvas · 3 pieces · no Frame" or "Pattern · Width 21 · Height 19 · 3.4 × 3.0 cm"). The Project's size lives in the Project panel and the Frame's size tooltip.
- **Menu and Project (ticket 431):** text buttons with their icon (`menu`, `pattern`) and the word "Menu" or "Project", before the zoom cluster, in that order. They open the Menu and Project panels (MenuPanel and ProjectPanel cards): a dropdown on every screen size. They sit on `ink` while theirs is open. Padding 0 14 0 12 and an 8px gap between icon and word keep the label off the button's edge. Menu is always there, with no Project open too (the strip then holds Menu alone, and during Convert image framing Menu and the zoom); Project is hidden, not disabled, with no Project. The New Project / Import bar has no Menu of its own any more.
- **Brand (ticket 540):** the X1 mark (22px, `accent`) and "openbeads" in the `brand` text style (Instrument Serif italic 24px, −0.3px, `ink`), 8px apart, the middle slot, centred on the strip whatever the sides hold. In the editor it is a link that opens the Overview; on the Overview it is the current page (`aria-current="page"`, no link). Under 1024px the wordmark hides and the logo stays. On a phone (under 744px) the editor's strip has no Brand; the Overview's keeps the logo.
- **Labels (ticket 540):** under 1024px the words of Menu, Project and Frame hide and their icons stay (the words remain for screen readers and Tooltips).
- **The Overview's strip** holds Menu, the Brand and the zoom (out, in, Fit), which scales the page's content 75–200% in the same 10% steps; Menu opens the editor's Menu panel, with Overview as its current page.
- **Controls, in this order:** Menu, Project, Rotate canvas, the Rulers toggle, Undo, Redo, zoom out, zoom in, Fit. Menu and Project (and Frame) are the left slot; Rotate canvas, Rulers, Undo and Redo sit in the right slot next to the zoom, right-aligned. They show only with a Project open (not while a picture is framed). There is no zoom level in percent, at any size (ticket 543). Zoom runs 10% to 400% in 10% steps; the tier's smallest-bead floor wins where it is higher. Icon buttons 30px (44px on a coarse pointer), 18px icons, radius-sm, no fill.
- **At every width, phones included.** When the strip is too narrow for the cluster it scrolls sideways (no visible scrollbar) and the buttons are never squeezed; Menu and Project stay at the left edge; only the canvas controls after them scroll.
- **Convert image framing:** the strip keeps Menu, the Brand and its own zoom (out, in, Fit) over the framing step's 100–800% range, since that zoom moves the picture under the fixed frame.
- **Rotate canvas (ticket 0471, ADR 0063):** the `rotate-canvas` icon (the `rotate` square ruled into four, like a canvas), plain look, just before Rulers at every width. Each press turns the whole picture a quarter clockwise (0, 90, 180, 270, 0); no bead, Frame or name moves. Name "Rotate canvas", no key, disabled with the reason "There are no beads to turn." while the Canvas is empty, and still available once a Row progress pass is done. Saved with the Project, no Undo step.
- **Rulers toggle:** the `ruler` icon; pressed is an `ink` fill with a `canvas` icon. Name "Rulers", `aria-pressed`. Shortcut `R`.
- **No Canvas color button (ticket 0443, spec 0440).** The background color and the Position marks (Dots | Squares) are set in Project (ProjectPanel card, Canvas section); in high contrast only Position marks remain. Every button left on the strip is a control-registry icon button, so its Tooltip carries the key chip (`R`, `Ctrl/Cmd+Z`, `Ctrl/Cmd+Shift+Z`, `Ctrl/Cmd+−`, `Ctrl/Cmd++`, `Ctrl/Cmd+0`) and says why it is disabled.
- The Zoom pill (a draggable pill with the same buttons, ticket 79) is gone; its buttons moved here.
