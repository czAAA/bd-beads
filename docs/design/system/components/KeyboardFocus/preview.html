Rules

  • Tab follows reading order: a "Skip to Pattern" link (visible on focus), the header, the left column top to bottom, the canvas strip, the Pattern, the Progress bar.
  • Inside the Toolbox each group is one stop; arrow keys move within tool tiles, swatches and segmented controls (roving tabindex).
  • The Pattern is one stop: arrow keys move a bead cursor, Space or Enter paints it, the shortcuts work as listed.
  • Modals, the Drawer and the modal Pattern sheet trap focus and return it to the opener. Escape closes the top-most thing first: modal → sheet or Drawer → menu → Selection → open disclosure row.
  • Focus is always visible (focus-ring, 2px, 2px away) and never hidden behind a sticky header or the Dock (scroll-margin).
