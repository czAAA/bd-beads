# BottomToolbar

The iPad mini's toolbar: the five tools (Paint, Fill, Select, Erase, Hand), the current colour, Undo and Redo, under the thumb so drawing never needs the drawer.

- Same anatomy as the phone Dock (64px plus the bottom safe-area inset, 22px icons over 11px labels, active tool in `accent`).
- Everything else lives in the Drawer, opened from the header.
- The Frame is not a tool here: it is set from the Frame row in the Drawer, or with the Set Frame button in the Progress bar (v16).

Hand-written from the responsive sign-off; static rendition.
