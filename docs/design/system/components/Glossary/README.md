# Glossary

The app's nouns in English and Russian, and the names of the 12 Palette colors.

- Pattern / схема; Bead / бисеринка (one), бисер (material and amounts); Technique / техника плетения; Palette / палитра; Row progress / прогресс по рядам; Row done / Ряд готов; Row not done / Ряд не готов; Beads needed / Нужно бисера; Delete all / Очистить всё; Frame / рамка (Set Frame / Задать рамку); piece / фрагмент; Canvas / холст; Hand / Рука; Rulers / Линейки (v16).
- Palette colors: Black, White, Red, Orange, Yellow, Green, Teal, Blue, Purple, Pink, Brown, Gray (Чёрный, Белый, Красный, Оранжевый, Жёлтый, Зелёный, Бирюзовый, Синий, Фиолетовый, Розовый, Коричневый, Серый); a custom color is "Custom" / «Свой цвет». Beads needed, the exports and screen readers use these names.

Hand-written from the Phase D sign-off; the v16 Russian terms are proposed, not yet reviewed.
