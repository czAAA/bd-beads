# PrintWordChart

The Word chart pages of the PDF, only when Letters is on: the written rows a weaver follows beside the chart (ticket 0574; glossary: Word chart).

- Header: "loom · {name} · {maker}", "Row by row" in Inter 600 with the row range in Instrument Serif italic `accent` ("1–24"), the page number on the right.
- A strip on `print-board` with the color key: letter swatches and names. Under it one line on reading the rows (which row is first, how a run reads).
- One line per row on `line-soft` hairlines: a 10 px tick box, the row number in DM Mono 500, the runs in DM Mono `ink`, and on the right the number of runs in `muted`. A long row wraps with a hanging indent; a row never splits across pages.
- The row format (count and letter, separators, peyote passes, (L)/(R)) is the one in ticket 0574.

New for the export sheets signed off on 2026-10-26 (ticket 0575).
