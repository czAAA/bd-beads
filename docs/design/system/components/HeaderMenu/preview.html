HeaderMenu · the menu next to the logo

One menu button beside the X1 mark and wordmark at every size, built on the Menu card. It replaces the More menu (OverflowMenu, archived in v15).

In the header, open, at every size

What it holds

  • Phone (0–743): Theme (opens the four-way theme sheet), Language, Name on exports, Keyboard shortcuts when a keyboard is attached; a rule; Overview, Take the tour. The imports stay in the Pattern sheet, as today.
  • iPad mini (744–1023): Import a file, Import QR code; a rule; Language, Theme, Name on exports; a rule; Overview, Take the tour.
  • 1024 and up: only Overview and Take the tour. The header's own controls stay where they are.
  • On /overview the menu holds Overview and Take the tour at every size. They are navigation links: no check on the current page, only aria-current="page" on Overview. Language and Theme sit in that page's header.
  • Icons: bead for Overview (the app's own mark), info for Take the tour; the rest keep the icons the More menu used. Values (Match device, English, Not set) sit right in meta, lowercased by style.

Button, menu, behaviour

  • Button: menu icon (new in Icons v2), right after the wordmark (after the mark on the phone), 10px gap. 34px ghost icon button from 744 (18px icon), 40px on the phone (20px icon). Hover --hover-fill, open --press-fill, focus the 2px focus-ring.
  • Menu: the Menu card: 4px under the button, left edges aligned, canvas / panel, 1px panel-line (line-strong in dark, 2px in high contrast), radius-md, elevation-3, padding 4. Items 40px below 1024, 34px from 1024; 16px icons; rules in line-soft. Layer z-popover 60.
  • Opens and closes with --duration-base (leaving 150ms), opacity and a 4px move, --ease-out / --ease-in; fades only under reduced motion.
  • Keyboard: Enter, Space or Down opens it and focuses the first item; Up opens on the last. Arrows move, Home / End jump, Enter chooses, Escape or Tab closes and focus goes back to the button.
  • Screen readers: the button is "Menu" / «Меню», aria-haspopup="menu", aria-expanded; the list is role="menu", items menuitem, rules separator. Items are links (a role="menuitem"). Take the tour starts step 1; Overview opens /overview.
