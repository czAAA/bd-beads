# Drawer

The iPad mini's left column, sliding in over the canvas from the left when the header's Tools button is pressed.

- 326px (`drawer-width`), on `canvas`, `elevation-3`, with the scrim over the rest; it holds the whole left column: Toolbox, save box, Beads needed, Saved Patterns.
- Escape, the scrim or Tools again closes it. It slides with `transform`; the canvas does not resize.

Hand-written from the responsive sign-off; static rendition.
