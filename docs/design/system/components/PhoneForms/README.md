# PhoneForms

New Pattern and Convert image framing on a phone.

- New Project is the Menu panel's subpanel (MenuPanel card), in the dropdown on a phone too: the primary Create Project button sits under the fields, then "or" and Convert image with its limits line; the system keyboard and pickers do the rest. There is no modal sheet for it (spec 0478).
- The Starter gallery (StarterGallery card) is the first block of that subpanel, one column of cards above the fields; a card pushes the Starter's setup one level deeper, with Create Project in the pinned footer, and Back returns to the gallery (ticket 0493).
- Framing takes the whole screen: header with close, the picture, then the controls and Create / Cancel at the bottom, in thumb reach.

Hand-written from the Phase A sign-off (forms, screens and states); static rendition.
