# PhoneForms

New Pattern and Convert image framing on a phone.

- New Project is the Menu panel's sub-view (MenuPanel card), in the Top sheet on a phone: Create is the 48px pinned footer button and Convert image sits under the fields; the system keyboard and pickers do the rest. There is no modal sheet for it (spec 0478).
- Framing takes the whole screen: header with close, the picture, then the controls and Create / Cancel at the bottom, in thumb reach.

Hand-written from the Phase A sign-off (forms, screens and states); static rendition.
