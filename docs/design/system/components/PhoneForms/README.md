# PhoneForms

New Pattern and Convert image framing on a phone.

- New Pattern opens as a full-height modal sheet from the Pattern sheet, with 48px Create and Convert buttons; the system keyboard and pickers do the rest.
- Framing takes the whole screen: header with close, the picture, then the controls and Create / Cancel at the bottom, in thumb reach.

Hand-written from the Phase A sign-off (forms, screens and states); static rendition.
