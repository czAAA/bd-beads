# FoundColorRow

One color Convert image found in the picture: what it became, how many beads, and the ways to change it. The rows make the Colors section's list, most beads first, under a heading row. (Ticket 0646, spec 0645; Change and the heading row, ticket 0758.)

- **Heading row** (ticket 0758): "From picture | Becomes | Beads | Change | Empty" in `meta-small` `muted`, over the rows' own columns (`--found-columns`: 64px for the picture's swatch and the arrow, the rest for the matched color and its two lines, then 56px each for Beads (right-aligned), Change and Empty (centred), 8px between), padding 4 4 4 6, a 1px `line-soft` rule under it, on the page's `box` fill. It is sticky: it stays at the top of the step as the rows scroll under it. Decorative (`aria-hidden`): each row names itself. A word wider than its column breaks rather than pokes out.

- **Row:** `panel-row-two-line` (40; 48 on touch), padding 0 4 0 6, a 1px `line-soft` rule above. In the heading's columns: the picture's color (20px swatch, radius 4, `swatch-edge`) with the arrow (12px `arrow-down` turned, `muted`); the matched color (20px; a dashed 1px `field-line` outline 1px out while the Bead color's hex is generated, as in BeadColors); two lines, the **color label** in `control` (ticket 0760: a catalog color is its code and the catalog's name, "DB723 Opaque Red", with the hex in a Tooltip on hover and long-press; a Custom color is its hex in DM Mono, with no Tooltip) over the source in `meta-small` `muted`, each wrapping when it is long (the build wraps rather than ellipsizes: a family and Finish such as Polish "Niebieski · Nieprzezroczysty" is wider than the row leaves it on a phone, and an ellipsis would hide the Finish); the bead count in `meta` `ink`, right-aligned; the actions.
- **What the lines say:**
  - a Bead color: "DB723 Opaque Red" over "Bead colors";
  - a Default Palette color: "Red" over "Default Palette";
  - Exact: "#d8312b" over "Custom color";
  - kept exact: "#f2c230" over "Kept exact · Custom color";
  - remapped: "Remapped · " before the source line ("Remapped · Bead colors");
  - empty: the matched swatch is an empty bead (`bead-empty`, a dashed `field-line` edge) and the lines read "Empty" over "No bead".
- **Actions:** two 28px icon buttons, each centred in its column, `aria-pressed`, an `ink` fill with a `canvas` icon when on: Change (the `palette` icon, also `aria-expanded`; on for a remapped or kept-exact row) and Empty (`erase`), each a control registry entry with a Tooltip (ticket 0650): "Pick the bead color this picture color becomes." and "Leave this color out, so its beads stay empty." Pressing the one that is on puts the row back to its match. Keep exact has no button of its own: it sits in the Change picker's head. Treat as empty, the switch in the Colors step (ConvertImage card), lets a tap on the preview press Empty on the row under it.
- **Change opens the row in place**, one row at a time: the row takes `surface` (`elevated` in dark; a 2px `line` edge in high contrast) and the picker hangs under it, padding 4 10 12. The picker is the colour popover's body (ToolPill card), the very component the Tool pill's popover is made of (ticket 0758: `ColorPopoverBody`, with nothing copied), so changing and adding a color work as they do when painting:
  - **Head**, as the popover's head: the found color's present color as a 20px swatch with its name and hex, then **Keep exact** (a small in-box button, `aria-pressed`, `ink` fill when on; it keeps the picture's own color, which joins the Palette as a Custom color), then Close (×). The popover's Edit palette pencil is left out: this Palette is the conversion's.
  - **The Palette** ("palette of the new Project" in place of "Palette"): the PaletteSwatches grid holding the Palette the new Project will get: its Brand's built-in colors, then every color the conversion uses that is not one of them, as added swatches. The current target carries the selected `ring`. Picking a swatch changes the found color to it; picking one another found color already uses merges the two. Pick color from canvas is left out (the preview's eyedropper is Treat as empty).
  - **Custom color**, the grid's last tile as in the popover (ColorPickers card): it opens the wheel, brightness slider and hex field under the grid; leaving them takes the color, which becomes the target and joins the grid as an added swatch.
  - **Palette {bead}** (in-box, with a chevron; only when the Bead has a Color catalog; "Palette Miyuki Delica 11/0", ticket 0745), under the grid as in the popover: it opens the BeadColors list (the Info button with the approximate note, the search with its Filters disclosure holding the Color and Finish filters with their live counts, the count line and empty state (ticket 0713), the rows; a code whose hex the Palette holds says "In the Palette"; the current target has a check). Picking a code changes the found color to it and the code joins the grid.
  - A pick applies at once and the preview redraws; the picker stays open. Close, Escape (or Change again) closes it and returns focus to Change. It opens in the row, not over the page, so a press elsewhere goes through and leaves it open.
- The mapping is applied after the snap, so changing the source keeps every keep, remap and empty and redoes the rest.
- **Screen readers:** each row is a `group` named "{picture hex} to {matched name}, {count} beads"; the swatches and the arrow are `aria-hidden`.
