# QrExport

The modal that shows a Pattern as a QR code, and its too-large state.

- A Modal (340px): title, the code, the Pattern's name and size, one line on how to use it, Close.
- The code always sits on white with dark modules, in both themes: scanners need the contrast. Its finder squares use the bead corner so it reads as the app's own.
- Too large: the warning message and Export Pattern (a file) as the way out.
- New copy, proposed: "Scan it with Import QR code on another device."

Hand-written from the Phase A sign-off (forms, screens and states); static rendition.
