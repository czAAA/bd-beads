# Mirror is live while drawing, not a discrete apply command

_Amended by ticket 50: live mirroring extends to Paste, not just the Paint tool. While a block is armed on the clipboard, hovering previews it at every Mirror strip (honouring axis counts and copy mode, or the single center axis when `VITE_RICH_MIRROR` is off), and clicking stamps every copy at once as one undo step, each keeping Paste's own hole rule and edge-clipping independently. "Mirror only applies to the Paint tool; Fill is unaffected by mirror state" below now reads: Fill and Delete all are unaffected; Paint and Paste both mirror live._

_Amended by the Toolbox redesign (2026-09-16): the single fixed center axis became a count of Mirror axes per direction (0 = off, up to one fewer than the cells across that direction), splitting the grid into equal strips — an axis may pass through a cell's middle, which then mirrors onto itself. Neighbouring strips are mirror images by default (A | A′ | A), so 1 axis behaves exactly as before; a separate copy-mode switch repeats strips unflipped (A | A | A) instead. Copy mode is its own switch rather than something the axis count implies, because tying "2+ axes means copy" to the count would make 1 axis the only true mirror and change what Mirror means as you step the count. "Mirror current" drops the "bigger half" heuristic for "the strip with the most painted cells is the source", falling back to 1 center axis when that direction's count is 0. Counts follow what's on screen: rotating the Pattern swaps the left–right and top–bottom counts. This richer Mirror ships behind a build-time feature flag (`VITE_RICH_MIRROR`, on locally, off on GitHub Pages until trusted); with it off, the original single center axis described below is what runs. The rest of this ADR — live mirroring while painting with Paint only, and keeping a one-time sync action — still holds._

Ticket 09 built Mirror as a discrete command: paint freely, then trigger "Apply" to reflect the drawn half onto the rest of the grid, using whichever half held more painted cells as the source. Reversed: with the Paint tool active and a mirror axis toggle on, painting a cell now immediately paints its mirrored counterpart(s) too (2 cells for one axis, 4 for both), and there's no "Apply" command anymore. Making mirroring live required fixing the axis at the grid's exact center — a well-defined "other side" per stroke — which retires the old adaptive "bigger half" heuristic for this path. Mirror only applies to the Paint tool; Fill is unaffected by mirror state.

That heuristic wasn't dropped, though: it still runs behind two small "Mirror current (horizontal/vertical)" buttons that do a one-time reflect of whatever's currently painted, per axis. Live mirroring only handles strokes drawn after an axis is turned on — these buttons cover syncing up content that was already there.

**Considered options**: dropping the discrete apply behavior entirely once mirroring went live (rejected — live mirroring can't retroactively fix content painted before an axis was enabled, so the manual per-axis sync stayed for that case).
