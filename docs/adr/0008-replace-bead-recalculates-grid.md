# Replacing a Pattern's Bead recalculates its grid, keeping real-world size fixed

Ticket 48 lets a Pattern's single Bead ([ADR 0007](0007-one-bead-per-pattern-no-color-mapping.md)) be swapped for a different catalog entry after it's created — something no earlier ticket provided; until now `beadId` was set once at creation and never changed. Swapping bead footprint (mm) forces a choice about what "recalculate" preserves: the Pattern's real-world size (mm) stays fixed, and the grid (columns × rows) is recomputed from the new Bead's footprint using the same math ticket 01 uses at creation — not the reverse (grid fixed, real-world size just relabeled). This matches the physical reality a beader cares about: the finished piece is being made at a specific real-world size, and picking a different bead just changes how many stitches that takes to fill.

Because the grid can grow or shrink, existing colors are rescaled onto the new grid by proportional nearest-cell resampling rather than cropped — approximating the same design at a different resolution, instead of silently truncating painted content the way Paste clips at the grid edge. Row progress and Mirror axis counts reset, since both are defined in terms of a grid dimension that may no longer exist. The whole operation — bead swap, grid resize, color rescale, and the two resets — is one undo step, consistent with Delete all (ticket 42) and Paste.

**Considered options**: keeping grid dimensions fixed and only relabeling the real-world size (rejected — makes picking a different Bead purely cosmetic, since the physical object the Pattern describes would silently change size instead of addressing "I picked the wrong bead"); anchoring and cropping instead of rescaling (rejected — a shrink would destroy content outside the fixed corner outright, and a grow would leave the new area blank, both worse for "the same design, different bead" than an approximate resample); blocking replacement whenever a Pattern has any painted cells (rejected — the motivating scenario is exactly a Pattern someone has already started painting).
