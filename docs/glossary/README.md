# Glossary

The domain language of bd-beads, one file per area. Each entry gives a term's meaning and, under _Avoid_, the words not to use for it. Find a term with `grep -rn '^\*\*Term' docs/glossary/`, then read that file; don't read them all.

| [Library, Palette and Beads](library-palette-beads.md) | Project library, Offline copy, Maker's name, Palette, Bead, Bead color, Color catalog, Form factor, Technique |
| [Row progress and Mirror](row-progress-and-mirror.md) | Row progress, Pass, Row direction, Progress bar, Mirror |

| [Import and rendering](import-and-rendering.md) | Convert image, Image colors, Project renderer, Drawing surface, Bead pointer |
| [Accounts and sharing](accounts-and-sharing.md) | View link, Guest, Free account, Pro, Edit link, Locked Project, Sync pending, Surface view |
