# Glossary: Library, Palette and Beads

The Project library, the Palette, Beads and their colors, Techniques. Part of the glossary split out of `CONTEXT.md` (ticket 380); the index is [README.md](README.md).

**Project library**:
Every Project saved on this device, taken together — what the Saved Projects box lists and what a library Project file (`openbeads_lib.openbeads`, gzipped; ADR 0048) exports in one go. It is ordered by last save, most recently saved first, with no grouping or nesting: saving a Project (any change to it, or Save) moves it to the front, a new or imported Project starts there, and a library saved before the order existed is put in order by when each Project was last changed (ticket 145). A Project belongs to the library from the moment it is created, and leaves it only by being removed. Lives only on the device that made it (ADR 0001), so moving it anywhere means exporting a Project file. Saves itself as it changes, so there is no Save button (ticket 523): the Project panel's save state says "saved · this device", or that the device refused, with Try again. Getting a Project onto another device is Export Project file (ticket 119). Every command persists the moment it lands, except a dragged paint or erase stroke, which is saved when the button is released. If a save doesn't get through — the browser's storage is full — the editor says so in a notice above the canvas and keeps the change on screen rather than losing it silently. Importing while a Project is open asks first whether to switch to the imported Project (saying the current one's progress is saved, or, after a failed save, offering to save it first); either way the imported Project joins the library, and with no Project open it opens without asking (ticket 154). The Saved Projects box asks too: the remove × asks "Remove this Project?" in a danger confirmation, and picking a different thumbnail asks "Switch Project?" naming both, with the same save-first offer after a failed save; picking the open Project does nothing (ticket 232). See ADR 0012.
_Avoid_: collection, gallery, saved list, workspace

**Offline copy**:
The app itself, kept on the device by the service worker after the first visit, so it opens with no internet or while our hosting is down (ticket 69, ADR 0045). It downloads silently; a newer one waits behind the open page until the person presses Reload in "Update ready", or the app is next opened. It holds no Projects: those are the Project library.
_Avoid_: cache, offline mode, downloaded app

**Keep note**:
The short note shown once per device, at the first time a Project is written to the library and only if the browser doesn't already keep it (ticket 399). It says in plain words that the browser may ask to keep this app's data, to tick "Remember this decision" and choose Allow so Projects survive a device short on space, and that after a decline Projects can still be cleared, so Save often and keep the Project file safe. Its button is what triggers the browser's own prompt; Skip doesn't ask the browser. Either way the device remembers it was shown. Opening the app never asks. A browser without the storage API, or one that decides silently, just never gets the note.
_Avoid_: permission prompt, storage popup

**Maker's name**:
Who made a Project: an optional name, at most 40 characters, printed on that Project's PDF and PNG exports and its background watermark, alongside the Project's own name. It belongs to the Project, not to the device, so it is set per Project (the New Project form, then "Name on exports") and travels with the Project (export, import, another device); there is no device-wide name and no fallback, and an empty name leaves the exports without one (ADR 0060, tickets 161, 182, 441).
_Avoid_: author, owner, signature, user name

**Palette**:
A Project's own set of colors used to paint its cells: built-in colors that come from the Project's Bead (its brand's set: Miyuki's 16 color families for Miyuki Delica, otherwise twelve; data source in the research note `brand-color-groups-for-default-palettes`, ticket 0527; ticket 0528), followed by the Custom colors that have joined it (no cap), in slots, saved in the Project and in its `.openbeads` file, so it is the same on every device. A swatch can be dragged to another slot (or moved with Alt+Left/Right), built-in ones too, and a removed color's slot closes up, so the slots never have a gap. A Custom color joins the last slot when the Custom color picker is left with it or it is taken from the canvas with Pick color from canvas. An added swatch can be removed again (never a built-in one): by Delete or Backspace on a focused one, or in Edit palette; either way it asks for confirmation first, painted cells keep their color, and an Undo toast puts it back. Removing the active color steps back to the default color. Adding, removing and moving a swatch are Undo steps. A new Project starts with the built-in colors. What is stored is what is shown: a built-in color a Project's Palette leaves out stays out. Every reader (image conversion, the screen-reader announcer, Beads needed, the picker, the tooltips) asks the Project's Palette. A color's name is a translation (a generic color) or a literal (a brand's own), one lookup for both, "Custom color" for an added one; the default color is the first built-in swatch. A swatch picked from the Color catalog keeps its maker's code (by its hex, saved in the Project and in the file from version 8, ticket 0538); painted cells still store only their hex. Replace Bead keeps a swatch's code only if the new Bead's catalog lists it in the new size, the rest become plain colors, all in the same Undo step. Independent from the bead catalog — a cell's color is not required to correspond to a real bead. Colors have ten shortcuts, Shift+1…9 and Shift+0: Shift+1, 2 and 3 pick the Tool pill's three recent colors (the painting color left out), and Shift+4…9 and Shift+0 pick the first seven slots whose color is not one of those recents, whichever color stands in them. A color that is one of the three recents is shown only as a chip in the pill (the colour popover's Palette skips it) and returns to its slot when it drops out; the Palette itself keeps it. See ADR 0002.
_Avoid_: color scheme, fixed palette

**Edit palette**:
A mode of the Palette in the color popover, entered with the pencil in its head row (shown only while the Palette has a Custom color) and left with the pencil again, Escape, closing the popover, or removing the last Custom color. While it lasts, each Custom swatch carries a large × and a click (or Enter, Space, Delete, Backspace on a focused one) asks to remove that color instead of choosing it; the built-in swatches are faded with a tip that default colors can't be removed, and Pick color from canvas and Custom color are disabled. Dragging a swatch to another slot still works. A bin after the word Palette ("Remove all custom colors") asks to remove every Custom color at once, naming how many; one Undo toast puts them all back in their slots. Both removals are guarded by a confirmation.
_Avoid_: manage colors, delete mode

**Bead**:
A catalog entry for a real bead line: a Brand, a Form factor and a Bead size (e.g. Miyuki Delica 11/0), not a color (that is a Bead color), with its own physical footprint in mm (used to convert an mm/cm size into a grid when a Project is created, and to work out an Estimated size — see ticket 01), width correction and beads per kg for that combination (ADR 0072, ticket 533), so nothing about a Bead is derived from its size alone. Width runs along the thread (the bead's length through its hole) and height across it (its diameter), so TOHO Round 11/0 is 1.5 × 2.2mm, not a 2.2mm ball. A Bead may carry a per-bead width correction (mm added to each column for thread and slack, measured rather than published — currently 0.15mm on TOHO Round 11/0), so a column is `widthMm + widthCorrectionMm` wide. Beads per kg is the maker's published figure; grams per bead are derived from it, and a Bead without one shows no Estimated weight. Its id is built from its parts (`miyuki/delica/11-0`), never changed or reused; the three ids from before are read through an alias map, and a Bead that leaves the catalog stays in it, flagged retired. A Project saves a full copy of its Bead and Form factor in its file (file version 7, ticket 534) and reads everything from that copy (drawing, Estimated size, Beads needed, weight), so it opens and draws the same whatever the catalog later does; a file without a copy gets the catalog's Bead of its id on open, and an id nobody knows stays the unknown Bead. A retired Bead is offered nowhere (not New Project, Template or Replace Bead) and stays in every file that has it. When the catalog's Bead of the same id differs from the copy in footprint, correction, outline, holes or beads per kg (names and labels do not count), Replace Bead lists the copy with an "(as saved)" postfix, not pickable, beside the catalog's current one; picking that one is an ordinary Replace Bead. Its Brand decides the Project's built-in colors (`defaultPalette`, see Palette); changing the Bead moves the Palette with it, in the same Undo step. The catalog is a fixed built-in list of three Beads (TOHO Cube 1.5mm, TOHO Round 11/0, Miyuki Delica 11/0), grown by adding data — see ADR 0007 and ADR 0072.
_Avoid_: seed bead type, item

**Bead color**:
One real color of a Bead line, identified by its maker's code (e.g. Delica `DB1`) and described by facts only: the maker's color family, a **Finish** and the Bead sizes it exists in, with a discontinued flag. No photo or durability rating is kept, and a hex only where a human has measured one (ADR 0072, ticket 536). In the color popover, "Bead colors" opens the catalog of the Project's Bead for its Bead size: each code is a swatch made from the color family and the Finish and shown as approximate (a measured hex replaces it), a discontinued code is marked, and a code whose hex the Palette already holds is shown as taken and cannot be added twice. Adding one is an Edit and the swatch joins as an added color; a Mix has no single color and is not listed (ticket 537).
_Avoid_: bead shade, catalog color

**Color catalog**:
A Brand's table of Bead colors (ADR 0072, ticket 536), its own entity: every Form factor of the Brand names it by `colorCatalog` (all Delica sizes share `miyuki-delica`); a Form factor with none, today every Form factor but Delica, has no catalog and its Beads keep the default colors. Each code row holds the maker code, color family, shared Finish, the maker's finish wording and sizes (`domain/colorCatalog.ts`). The data is JSON in `src/data/colorCatalogs/`, made by `scripts/build-color-catalog.mjs` in the docs repo from Miyuki's public directory and run by hand, and is loaded by `services/colorCatalogs.ts` as one lazy chunk per catalog, validated on load, so it is never in the main bundle. Delica holds 1,919 codes (1,288 of 11/0). Open to everyone, a Guest included. See ADR 0002.
_Avoid_: color library, swatch catalog

**Finish**:
The one shared list every Brand's own finish wording is mapped onto: transparent, opaque, ceylon, silver-lined, luster, matte, rainbow, metallic, plated (ticket 536). A code keeps the maker's wording beside it for display (Miyuki's "Opaque · Metallic" is metallic). Where Miyuki gives several tags, the first of plated, metallic, rainbow, matte, silver-lined, luster wins, else its glass type decides.

**Form factor**:
The shape of a family of Beads (e.g. round, Delica, cube), a lookup row that carries its outline and its number and direction of holes, so a new shape is data, not code (ADR 0072). Its name is a translation. In a Real Bead shape it decides the outline of a project cell.
_Avoid_: bead outline
**Brand**:
The maker of a Bead (TOHO, Miyuki), a lookup row with a literal name. It decides the Project's built-in colors and, later, the Color catalog. Not the app's Wordmark.
_Avoid_: manufacturer, make
**Bead size**:
A Bead's size as its maker states it (11/0, 1.5mm), a literal. It is part of the Bead's id and says nothing by itself about the footprint: 11/0 is 1.6mm for Delica, 2.0mm for Miyuki Round and 2.2mm for TOHO Round.
_Avoid_: bead number, gauge

**Bead shape**: a Project setting, Symmetric or Real, chosen in the New Project form and the Project panel and saved with the file (older files and Templates read as Symmetric). Symmetric draws square cells, as before. Real draws each cell with the Bead's real proportions (width along the thread, height across it) and an outline from its Form factor: a rounded rectangle, so a Delica reads as a cylinder seen from the side. Applies to both layers, since a Project has one Bead. Grid positions, sizes counted in beads and Beads needed are the same in both.
_Avoid_: cell shape

**Brick block**: the number of brick stitch rows woven straight on top of each other before the next rows shift half a bead, 1 to 20, default 1 (today's every-other-row shift). With N, rows alternate in blocks: N straight, N shifted, and so on, so the shift repeats every 2N rows and a Frame's top edge resizes by a multiple of 2N rows. Brick stitch only: a stepper beside the Technique choice (new Project form, the Frame menu and, for the Canvas, the Project panel), hidden for loom and peyote, kept if the Technique is switched away and back. A setting of each layer saved with the file (older files read as 1); changing it on an open Project is one Undo step that keeps every bead's row and column, and the Frame's waits while Row progress is on. Its hover text says what it does.

**Net size** (ticket 485): in Netting, the number of beads in one loop, the middle one shared with the next row ("3-bead netting"): an odd number from 3 to 9, default 3, so each side of a diamond holds (Net size − 1) / 2 beads between its shared beads. Netting only, chosen when the Project is created and chosen when a layer becomes Netting (new Project, or switching to it) and fixed after, since a diamond with more beads gives the old beads no faithful place; saved with the file. Chosen with a stepper that goes by two, in the New Project form in the place the Brick block stepper takes and in the confirmation of a switch to Netting; no panel offers a change on a Netting layer.

**Netting** (ticket 485): a Technique woven as an open diamond mesh, in horizontal rows: diagonal strands of beads meet at shared beads, with holes between them. Positions stay (row, column) at a step of three quarters of a bead each way: with p = (Net size + 1) / 2 a position is a bead when it lies on a diagonal through a shared bead (the shared beads sit every p positions down and across), so a diamond is 2p positions wide and tall and holds Net size beads, and a Frame of U by V diamonds holds 2pU + 1 columns and (V + 1)p + 1 rows, starting on a multiple of 2p each way. Printed 3-bead and 5-bead patterns are to check this lattice against (ticket 485). A hole is not a position: nothing paints it, Convert image skips it and no export draws it. Beads are drawn round and untilted at their places on the diamond, shared beads like the rest. A quarter turn of a diamond row is not a row, so Rotate and Rotate Frame are not offered, and Row direction stays on rows (Turn row direction is not offered). A Frame holds whole diamonds only, its edges cutting through shared beads: no foundation row or side turn loops. Vertical netting is not planned yet.
_Avoid_: net, mesh weave

**Right-angle weave** (ticket 482; editing as whole Units ticket 483, Row progress ticket 484): a Technique woven in square units of four beads, each unit sharing its sides with its neighbours, so half the beads lie horizontally and half vertically. Every bead is a position of its own, painted on its own, and drawn the way it lies: horizontal beads turned sideways, vertical beads upright. A Unit's side is a bead's length along its hole plus its width. Positions stay (row, column): rows alternate between a line of horizontal beads (one per Unit across) and a line of vertical beads (one more), so a Frame of U by V Units holds U + 1 columns and 2V + 1 rows, the last column of each horizontal line empty. Rotate turns whole Units, so a quarter turn makes a horizontal bead vertical (not offered until ticket 483). Monastery weave is not planned yet.
_Avoid_: crossweave, cross weave (the two-needle way of working the same weave, not a Technique of its own)
_Avoid_: cross weave, RAW (the Russian and Belarusian UI may call it "крестик")

**Unit** (Right-angle weave: ticket 482; Netting: ticket 485): the repeating cell of Right-angle weave (a square of four beads) or Netting (one diamond); what columns and rows count in those Techniques, so a Project's size, the Frame, the rulers and Row progress count Units and the Frame snaps to whole Units, while Bead quantities count real beads. Loom, peyote and brick stitch have no Units: there columns and rows count beads.
_Avoid_: cell, square, diamond (as a size)

**Technique**:
The weaving method used (loom, peyote, brick stitch, Right-angle weave, Netting), which determines the grid geometry/offset of a layer's cells. A Project has a **Canvas Technique** and a **Frame Technique** (ticket 492, ADR 0038): each layer is woven in its own, a peyote Frame on a loom Canvas or the other way round, and one bead catalog entry serves the whole Project. Each is chosen when its layer is made: a new Project's Canvas takes the Technique the form chose and its Frame the same; a Frame made later from a Selection or Fit to drawing takes the Canvas's. The Frame's can be changed on an open Project from the Frame menu (ticket 351): only the geometry changes (row shift and row pitch), so the Frame keeps its columns, rows, Bead and place and every cell keeps its row and column (a picture drawn for one technique will look different in another). One undo step; it waits while Row progress is on. The Canvas's is a row in the Project panel beside the Bead, enabled at any time, and keeps every Canvas bead's row and column too. A layer's own first row is always an unshifted one, so nothing needs to start on an even row once a Frame exists. All five switch among each other (ticket 0502, ADR 0038): a bead keeps its row and column where the new Technique has a position there and is dropped where it has none, after a confirmation that says how many beads would be lost, asked only when the layer has drawn beads.
_Avoid_: stitch, weave type
