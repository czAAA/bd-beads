# Contributing

Thanks for your interest in bd-beads.

## Issues are welcome

Found a bug or have an idea? [Open an issue](https://github.com/czAAA/bd-beads/issues/new/choose). For a bug, say what you did, what you expected and what happened instead, and which browser and device you used. A screenshot or a small pattern file that shows the problem helps a lot.

Security problems go through private reporting instead; see [SECURITY.md](SECURITY.md).

## Pull requests aren't accepted yet

The project isn't taking outside code contributions for now, so pull requests from forks will be closed. That may change later; if it does, this file will say how.

## Running it yourself

You can still build, run and change the app for yourself under the [AGPL-3.0](LICENSE): `npm ci`, then `npm run dev`. See the [README](README.md) for the checks.
