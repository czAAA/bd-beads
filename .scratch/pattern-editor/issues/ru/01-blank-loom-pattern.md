# 01: Создание и сохранение пустой схемы (Loom)

**Что нужно сделать:** Пользователь выбирает бисер из стартового каталога, вводит размер схемы в см/мм и создаёт новую схему с техникой Loom (единственная техника в этом тикете). Отображается пустая сетка нужного размера, схема автоматически сохраняется в localStorage и остаётся после перезагрузки страницы.

**Блокируется:** ничем (можно начинать сразу)

**Статус:** ready-for-agent

- [ ] Пользователь может создать новую схему, выбрав бисер из стартового каталога (TOHO Cube 1.5мм, TOHO Round 11/0, Miyuki Delica 11/0) и технику Loom
- [ ] Пользователь вводит размер схемы в см или мм; приложение пересчитывает его в сетку бусин (столбцы × строки) через размер выбранного бисера
- [ ] Отображается пустая прямоугольная сетка с нужным количеством столбцов/строк
- [ ] Схема (техника, бисер, размеры, пустая сетка) сохраняется в localStorage без явного действия "сохранить"
- [ ] После перезагрузки страницы ранее созданная схема отображается без изменений
