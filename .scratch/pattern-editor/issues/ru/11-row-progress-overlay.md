# 11: Оверлей прогресса по рядам

**Что нужно сделать:** Переключатель внутри редактора схемы, включающий оверлей прогресса по рядам: последовательный указатель "текущая строка" (продвигается вперёд, можно вручную сдвинуть назад), с приглушёнными завершёнными строками, выделенной текущей строкой и обычным отображением оставшихся строк. Состояние сохраняется вместе со схемой.

**Блокируется:** 01

**Статус:** ready-for-agent

- [ ] Переключатель показывает/скрывает оверлей прогресса по рядам, не выходя из обычного редактора
- [ ] Оверлей показывает один указатель "текущая строка", продвигающийся по мере отметки строк как готовых
- [ ] Указатель можно вручную сдвинуть назад, к более ранней строке
- [ ] Строки до указателя отображаются приглушённым/серым цветом; текущая строка выделена отдельной подсветкой; строки после указателя — в обычных цветах схемы
- [ ] Состояние прогресса по рядам сохраняется в localStorage вместе с остальной схемой
