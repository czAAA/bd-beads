# 07: Ручная раскраска ячеек и отмена действия

**Что нужно сделать:** Пользователь выбирает цвет из палитры и кликает по ячейкам сетки, чтобы закрасить их; отдельное действие "отменить" откатывает последнее действие раскраски.

**Блокируется:** 01

**Статус:** ready-for-agent

- [ ] Пользователь может выбрать цвет из палитры
- [ ] Клик по ячейке закрашивает её выбранным цветом независимо от техники/геометрии схемы
- [ ] Отмена (undo) откатывает последнее действие закрашивания; повторные нажатия откатывают дальше
- [ ] Закрашенное состояние сохраняется в localStorage вместе с остальной схемой
