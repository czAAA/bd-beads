# 07: Сопоставление цвет→бисер и подсчёт количества

**Что нужно сделать:** Универсальное сопоставление по умолчанию для каждого цвета палитры → конкретный бисер, с возможностью переопределить в конкретной схеме, плюс расчёт списка закупки — сколько бусин каждого цвета нужно для схемы. См. [ADR 0002](../../../../docs/adr/0002-palette-separate-from-bead-catalog.md).

**Блокируется:** 03, 06

**Статус:** ready-for-agent

- [ ] У каждого цвета палитры может быть один глобальный бисер по умолчанию (сохраняется для всех схем)
- [ ] Внутри конкретной схемы сопоставление для цвета можно переопределить, не затрагивая глобальный дефолт и другие схемы
- [ ] Для конкретной схемы приложение считает и показывает общее количество бусин по каждому цвету на основе закрашенных ячеек
- [ ] В списке количества используется переопределение для схемы, если оно задано, иначе — глобальный дефолт
