# 07: Команда отражения

**Что нужно сделать:** Переключатель отражения с независимыми чекбоксами осей (горизонталь/вертикаль); при активации команда отражает уже нарисованную половину схемы относительно выбранной оси/осей.

**Блокируется:** 05

**Статус:** ready-for-agent

- [ ] Общий переключатель включает/выключает режим отражения
- [ ] Чекбоксы горизонтальной и вертикальной оси выбираются независимо (любая, обе или ни одна)
- [ ] Команда "отразить" переносит уже закрашенные ячейки на остальную часть сетки относительно выбранной оси/осей
- [ ] Отражение — это отдельная команда, применяемая по нажатию, а не режим реального времени при рисовании
- [ ] Действие отражения отменяется через undo
