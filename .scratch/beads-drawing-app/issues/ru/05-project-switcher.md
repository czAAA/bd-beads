# 05: Переключение между несколькими сохранёнными схемами

**Что нужно сделать:** Заменить нынешнюю модель хранения одной схемы (единственная запись `bd-beads:pattern` в localStorage, без возможности вернуться к форме создания новой схемы, если одна уже создана) на поддержку нескольких сохранённых схем одновременно. Пользователь должен всегда видеть, какая схема сейчас открыта, уметь переключиться на другую сохранённую, удалить схему и начать новую, не теряя остальные. Пока достаточно списка сохранённых схем под холстом схемы — отдельный полноценный экран проектов можно сделать позже.

**Блокируется:** 01

**Статус:** ready-for-agent

- [ ] Интерфейс всегда показывает, какая схема сейчас открыта (например, название или сводка по бисеру/размеру)
- [ ] Список всех сохранённых схем отображается под холстом схемы; клик по схеме в списке переключает редактор на неё
- [ ] Каждую схему в списке можно удалить; при удалении открытой схемы редактор переключается на другую существующую схему, если она есть, либо на пустой стартовый экран, если схем не осталось
- [ ] Действие "новая схема" видимо всегда (не только при первом визите), чтобы можно было начать ещё одну схему, не теряя существующие
- [ ] Все сохранённые схемы хранятся в localStorage согласно [ADR 0001](../../../../docs/adr/0001-local-only-persistence.md), заменяя собой единственный ключ хранения схемы
- [ ] Новые и существующие подписи/кнопки этой функциональности подключаются к механизму i18n из тикета 03 и дизайн-токенам из тикета 02, а не используют одноразовое оформление или захардкоженный текст
