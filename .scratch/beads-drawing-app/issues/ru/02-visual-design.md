# 02: Творческий, яркий и уютный визуальный дизайн

**Что нужно сделать:** Заменить нынешнее минималистичное оформление на продуманную систему визуального дизайна, применённую во всём приложении (фон, типографика, кнопки, элементы форм, обрамление сетки схемы) — творческую и яркую, но уютную, а не строгую или крикливую.

**Референс стиля:** плоская иллюстрация в стиле хендмейд — насыщенные плоские цветовые блоки (без градиентов), уверенные толстые контуры, органичные рисованные формы, местами лёгкая текстура "мелка"/каракулей для теплоты, много белого/светлого пустого пространства. Основа палитры («Japan Color Palette»): селло (тёмно-синий, текст), перечная мята (светлый фон), амарант (красный), веджвуд (синий), аква-айленд (мягкий бирюзовый).

**Блокируется:** 01

**Статус:** done

- [ ] Палитра и типографика определены как переиспользуемые дизайн-токены (например, CSS custom properties), а не разовые значения "в разметке"
- [ ] Палитра соответствует референсу стиля: насыщенные плоские цветовые блоки — селло, перечная мята, амарант, веджвуд, аква-айленд — на светлом/белом фоне
- [ ] Применено единообразно по всему уже реализованному интерфейсу (форма создания схемы, кнопки, заголовки, обрамление сетки), а не на одном экране
- [ ] Текст и интерактивные элементы сохраняют читаемый контраст на новой палитре
- [ ] Токены переиспользуемы, чтобы интерфейс из следующих тикетов (сетки других техник, образцы палитры, управление каталогом и т.д.) мог использовать их без повторного определения цветов
