# 16: Масштабируемый холст схемы, ограниченный размером экрана

**Что нужно сделать:** Холст схемы всегда рендерится в собственном блоке фиксированного размера, который помещается на экране, независимо от размера сетки схемы. Если сетка схемы больше блока, она открывается уменьшенной ровно настолько, чтобы показать её целиком; элементы управления увеличением/уменьшением позволяют изменять масштаб в любой момент работы.

**Блокируется:** 01, 14

**Статус:** ready-for-agent

- [ ] Блок холста имеет фиксированный максимальный размер, который всегда помещается в видимую область экрана, независимо от размера сетки схемы
- [ ] Открытие схемы, чья сетка больше естественного размера блока, автоматически уменьшает масштаб, чтобы показать сетку целиком; схема, которая уже помещается, открывается на 100%
- [ ] Элементы управления увеличением/уменьшением доступны всё время, пока схема открыта, ограничены разумным диапазоном, с возможностью сбросить масштаб к уровню, подходящему для текущей схемы
- [ ] Переключение на другую схему заново подбирает масштаб под неё, а не сохраняет масштаб предыдущей схемы
- [ ] Масштабирование — это только визуальное преобразование: оно никогда не меняет данные схемы (закрашенные ячейки, размеры)
- [ ] Оформление использует дизайн-токены из тикета 02, а не разовые стили
