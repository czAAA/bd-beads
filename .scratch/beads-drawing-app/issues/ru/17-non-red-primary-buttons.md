# 17: Красный цвет — только для разрушительных действий

**Что нужно сделать:** Кнопки перестают быть красными по умолчанию везде в приложении. Основные/нейтральные действия (Новая схема, управление масштабом, выбор инструмента и т.д.) используют не красный цвет из существующей базовой палитры; красный (amaranth) становится отдельным стилем «разрушительного действия», который применяется явно — например, к удалению сохранённой схемы — а не оказывается цветом по умолчанию для всех кнопок случайно.

**Блокируется:** Ничем (можно начинать сразу)

**Статус:** ready-for-agent

- [ ] Стиль кнопки по умолчанию (`style.css`) больше не использует красный/amaranth цвет из базовой палитры
- [ ] Существует отдельный, явно применяемый стиль кнопки для разрушительных действий, использующий красный/amaranth цвет
- [ ] Кнопка «Удалить» в списке сохранённых схем (и любое другое действие типа удаления) использует стиль разрушительного действия
- [ ] Все остальные существующие кнопки (Новая схема, увеличение/уменьшение/сброс масштаба, выбор инструмента рисования/заливки, отмена) отображаются в новом стиле по умолчанию (не красном)
- [ ] Состояния наведения/фокуса/недоступности остаются читаемыми на новом цвете по умолчанию
