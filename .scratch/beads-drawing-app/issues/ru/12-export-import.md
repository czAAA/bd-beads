# 12: Экспорт и импорт файла схемы

**Что нужно сделать:** Пользователь может экспортировать текущую схему (техника, бисер, размеры, закрашенные ячейки, сопоставления цветов) в файл и импортировать ранее экспортированный файл, чтобы восстановить/открыть схему. См. [ADR 0001](../../../../docs/adr/0001-local-only-persistence.md).

**Блокируется:** 01

**Статус:** ready-for-agent

- [ ] Пользователь может экспортировать открытую схему в скачиваемый файл
- [ ] Пользователь может импортировать этот файл обратно и получить идентичную схему (та же сетка, цвета, техника, бисер, сопоставления)
- [ ] Весь процесс работает полностью на стороне клиента, без сервера
