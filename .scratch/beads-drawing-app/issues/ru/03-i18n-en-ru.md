# 03: Локализация интерфейса с переключателем EN/RU

**Что нужно сделать:** Добавить в приложение слой i18n, чтобы весь текст интерфейса (подписи, кнопки, заголовки) можно было показывать на английском или русском, с видимым переключателем между языками. Использовать русские термины, уже зафиксированные в разделе Language файла [CONTEXT.md](../../../../CONTEXT.md) (например, Схема для Pattern, Бисеринка для Bead, Техника плетения для Technique), а не переводить заново.

**Блокируется:** 01

**Статус:** ready-for-agent

- [ ] У каждого элемента интерфейса, который уже реализован (подписи/варианты формы создания схемы, кнопки, заголовки), есть перевод и на английский, и на русский
- [ ] Видимый переключатель позволяет пользователю в любой момент переключить язык интерфейса между EN и RU
- [ ] Русские переводы используют ровно те термины, что в глоссарии CONTEXT.md, без новых/расходящихся формулировок
- [ ] Выбранный язык сохраняется между перезагрузками (localStorage, в соответствии с [ADR 0001](../../../../docs/adr/0001-local-only-persistence.md))
- [ ] По умолчанию при первом визите (без сохранённого выбора) используется русский язык
- [ ] Интерфейс, который появится в следующих тикетах, должен подключаться к тому же механизму перевода, а не быть одноразовым решением
