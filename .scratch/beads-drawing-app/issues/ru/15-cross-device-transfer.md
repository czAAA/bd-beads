# 15: Перенос сохранённых схем между устройствами через экспорт/импорт

**Что нужно сделать:** Расширить механизм экспорта/импорта (тикет 12), чтобы пользователь мог переносить всю свою работу между двумя устройствами: экспортировать всю библиотеку сохранённых схем (тикет 05), включая состояние прогресса по рядам (тикет 13), в один файл и импортировать его на другом устройстве/в другом браузере, чтобы продолжить ровно с того места, на котором остановились. См. [ADR 0001](../../../../docs/adr/0001-local-only-persistence.md), где это предусмотрено как ручной перенос файла, а не постоянная синхронизация через сервер.

**Блокируется:** 05, 12, 13

**Статус:** ready-for-agent

- [ ] Пользователь может экспортировать все сохранённые схемы (а не только открытую) в один скачиваемый файл
- [ ] Пользователь может импортировать этот файл на другом устройстве/в другом браузере и получить те же сохранённые схемы, идентичные исходным (та же сетка, цвета, техника, бисер, сопоставления, состояние прогресса по рядам)
- [ ] При импорте схемы, которых ещё нет локально, добавляются, а не перезаписывают существующие молча; схема с тем же идентификатором, что и уже существующая локально, импортируется как отдельная запись, а не сливается с ней
- [ ] Весь процесс работает полностью на стороне клиента, без сервера
