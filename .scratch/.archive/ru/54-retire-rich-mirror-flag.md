# 54: Убрать фича-флаг расширенного Отражения

**Что сделать:** у Отражения остаётся одна реализация. Количество осей по каждому направлению и режим копирования — это просто то, как Отражение работает; поведение с единственной центральной осью, которое они заменили, удаляется вместе с переключателем между ними.

Для пользователя не меняется ничего: флаг включён во всех сборках с момента выхода.

- **Удаляется флаг**: его модуль, его тест, отслеживаемый в git `.env`, который его задаёт, и запись в объявлении типов переменных окружения.
- **В домене остаётся один набор функций Отражения** — тот, что работает с количеством осей, — переименованный в простые имена. Суффикс «ForCounts» всегда означал только «не устаревшая версия», и теряет смысл в тот момент, когда устаревшая удалена.
- **Удаляются тип осей вкл/выкл и эвристика «большей половины»** вместе со вспомогательными функциями, существующими только ради них.
- **Из App.vue уходят** константа флага, шесть ветвлений по нему и два computed, единственной задачей которых был перевод устаревших булевых флагов в количество осей для Вставки.
- **Из Панели инструментов уходят** проп флага, альтернативная отрисовка и событие переключателя вкл/выкл.
- **Основной интеграционный набор тестов перестаёт подменять флаг.** Одна удалённая строка переводит около 145 тестов — Кисть, Заливка, Отменить, хранение, Прогресс по рядам, Очистить всё, Заменить бисер, Количество бисера, выгрузка и загрузка, Выделение/Копировать/Вставить, Группы инструментов — на проверку той конфигурации, которая реально работает у пользователей.
- **Около 7 тестов Отражения переносятся** на счётчики осей, потому что аналогов в наборе «с флагом» у них нет и их покрытие иначе будет потеряно: отмена и повтор закраски с живым Отражением, независимость Заливки от Отражения, протянутый штрих с Отражением, стирание правой кнопкой с Отражением, предпросмотр при наведении с Отражением, блокировка готовых рядов против отражённой ячейки и Очистить всё при включённом Отражении.
- **Около 2 тестов удаляются**: это утверждения об интерфейсе с выключенным флагом, который больше ничего не описывает.
- **В ADR 0006 добавляется третье дополнение**, фиксирующее отказ от флага.

**Блокируется:** 53 (проверки в CI) — это самый крупный дифф в наборе, и он должен приезжать уже при работающей проверке тестами

**Статус:** ready-for-agent

**Решения (2026-09-17):**
- Второе дополнение к ADR 0006 сохраняло флаг, «чтобы его можно было быстро выключить». Проверено по git: флаг создан тикетом 44, включён один раз и ни разу не выключался. `.env` отслеживается git, поэтому выключение всегда означало правку закоммиченного файла, push и ожидание деплоя на Pages — ровно столько же, сколько `git revert`. Флаг не давал никакой скорости отката сверх той, что уже есть у git.
- Точка отката в любом случае устарела: тикеты 48 и 50 вышли уже после включения флага, поэтому выключение сегодня вернуло бы не проверенную конфигурацию, а такую, где Вставка идёт по пути с переведёнными булевыми флагами, который в продакшене никогда не работал.
- Переименование оставшихся функций едет в этом же диффе, а не отдельным тикетом. Различающие имена осмысленны, только пока существуют оба варианта; сохранять их после удаления значит оставить различие, у которого больше нет второй стороны.
- Интеграционный набор тестов здесь **не** перестраивается, несмотря на размер. Его размер — следствие размера App.vue, поэтому перестройка уместна после тикета 55, который даст ему более мелкие единицы для проверки. Набор «с флагом» тоже пока остаётся отдельным, чтобы перенесённые тесты было легко сверить с уже существующими.

- [ ] Нигде в приложении нет модуля флага, отслеживаемого `.env` с флагом, записи в типах окружения, пропа или ветвления по флагу
- [ ] Домен предоставляет один набор функций Отражения под простыми именами
- [ ] Тип осей вкл/выкл и эвристика «большей половины» удалены вместе со вспомогательными функциями
- [ ] Основной интеграционный набор больше не подменяет флаг, а всё покрытие, существовавшее только при выключенном флаге, либо перенесено, либо удалено осознанно
- [ ] В ADR 0006 есть третье дополнение об отказе от флага
- [ ] Весь набор тестов зелёный, Отражение работает ровно так же, как сегодня в обычной сборке
