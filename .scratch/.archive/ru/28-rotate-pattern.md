# 28: Поворот отображения схемы между горизонтальной и вертикальной ориентацией

**Что нужно сделать:** Кнопка-значок "Повернуть" в панели инструментов (рядом с "Отменить"), которая переключает отображение открытой схемы на 90° — как поворот фотографии: чисто визуальное переключение, а не редактирование. По клику весь отрисованный рисунок (сетка, смещение рядов, линейки — всё вместе) поворачивается на 90°; повторный клик возвращает как было. Сами данные сетки, `columns`/`rows`, `widthMm`/`heightMm` и техника плетения никогда не меняются — меняется только то, как схема показывается на экране.

**Правка (2026-09-16):** Первая реализация этого тикета на самом деле транспонировала данные сетки (меняла местами `columns`/`rows` и заново пересчитывала геометрию смещения для каждой техники на повёрнутых данных). Пользователь протестировал и отклонил это: для Пейот/Кирпичного стежка смещение рядов пересчитывается с нуля построчно на повёрнутых данных, из-за чего прямая диагональная линия после поворота превращалась в ломаную, визуально другую фигуру — "меняется схема плетения", а не просто ориентация. Просьба пользователя, дословно переформулированная: поворачивать как переключение ориентации в фоторедакторе/графическом редакторе — в самом рисунке не должно меняться вообще ничего, ни для одной техники. Переделано на флаг-переключатель отображения (`Pattern.rotated: boolean`), а сам поворот на 90° применяется как CSS-трансформация ко всему отрисованному холсту (сетка + линейки вместе), так что поворачивается ровно та же самая отрисованная картинка целиком, без пересчёта геометрии. См. [[feedback_rotate_offset_techniques]] (память) с исправленным правилом.

**Статус:** done

- [ ] Кнопка-значок "Повернуть" (два перекрывающихся прямоугольника — портретный поверх альбомного, не стрелка, чтобы не читаться как "отменить/обновить") находится в карточке "Отменить" панели инструментов и по клику переключает флаг `rotated` активной схемы
- [ ] Поворот — это чисто флаг отображения: сетка, `columns`/`rows`, `widthMm`/`heightMm` и техника доказуемо не меняются (те же самые объекты) до и после переключения
- [ ] Отрисованный холст (сетка + все четыре линейки) поворачивается на 90° как единый повёрнутый блок, отцентрированный так, что его габариты точно совпадают с обменёнными шириной/высотой — смещение рядов для Пейот/Кирпичного стежка поворачивается вместе с рисунком вместо пересчёта на повёрнутых данных, поэтому то, что было прямой диагональю, остаётся прямой диагональю
- [ ] Раскрашивание/клики по клеткам работают корректно через повёрнутое отображение (проверено кликами по реальным координатам, а не только синтетическими событиями) — DOM-элемент под курсором, а значит и то, какая логическая клетка сетки будет раскрашена, не зависит от CSS-трансформации
- [ ] Поворот — не шаг отмены (это не редактирование сетки) и не затрагивает стек отмены
- [ ] Масштаб холста сразу подстраивается под обменённые габариты после переключения
- [ ] Сводка схемы в шапке (`название · ШxВ`) отражает текущее повёрнутое отображение с обменёнными размерами, даже если сохранённые `columns`/`rows` не изменились
- [ ] Работает одинаково для любой техники (Ткачество, Пейот, Кирпичный стежок) — без особого поведения для конкретной техники, и ни одна техника не выглядит визуально иначе после цикла "повернуть — повернуть обратно"
