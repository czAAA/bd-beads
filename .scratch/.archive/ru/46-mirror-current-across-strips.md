# 46: «Отразить текущее» по полосам

**Что нужно сделать:** Кнопка «Отразить текущее» для каждого направления один раз синхронизирует уже нарисованное по осям этого направления: полоса с наибольшим числом закрашенных ячеек становится источником и копируется на все остальные полосы — по умолчанию зеркально, а при включённом режиме копирования без отражения. Если счётчик этого направления 0, действует как одна ось по центру, так что кнопка всегда что-то делает. Один шаг отмены; сплетённые ряды остаются заблокированными, как для других команд рисования.

Часть расширенного отражения (флаг вводится в задаче 44): при выключенном `VITE_RICH_MIRROR` «Отразить текущее» работает как сейчас — по правилу «большей половины» относительно центра.

**Блокируется:** 44, 45

**Статус:** ready-for-agent

**Решения (2026-09-16):**
- Правило «большей половины» заменяется на «полоса с наибольшим числом закрашенных ячеек» (пометка в ADR 0006). С одной осью это то же самое, что раньше.
- Учитывает режим копирования.
- При равенстве полос берётся первая (левая/верхняя) — как сейчас при равных половинах.

- [ ] Счётчик 0: работает как отражение по одной центральной оси в этом направлении
- [ ] Счётчик N: самая заполненная полоса копируется на все остальные с чередованием отражения
- [ ] При включённом режиме копирования копируется без отражения
- [ ] Одно «Отменить» всё возвращает
- [ ] При включённом прогрессе сплетённые ряды не меняются
- [ ] При выключенном флаге расширенного отражения «Отразить текущее» работает точно как сейчас (существующие тесты проходят без изменений)
