# 40: Группы инструментов с заголовками в сетке из двух рядов

**Что нужно сделать:** Панель инструментов делится на пять групп с заголовками, в таком порядке: Инструменты (Кисть, Заливка, Выделение), Цвета (палитра), Правка (Отменить, Повернуть, Копировать), Отражение, Прогресс по рядам. У каждой группы в левом верхнем углу — маленький неброский заголовок. Внутри группы элементы идут слева направо в два ряда, не больше семи в ряду, поэтому группа занимает ровно столько ширины, сколько нужно: группа из трёх кнопок узкая, группа цветов — широкая. Текстовые и числовые элементы (например, «ряд X / Y» в прогрессе по рядам) занимают отдельный ряд целиком и не входят в сетку из 14 мест.

Сначала подготовительный рефакторинг отдельным коммитом без изменения поведения: вынести разметку и обработчики панели инструментов из оболочки приложения в отдельный компонент Toolbox — задачи 41–47 строятся на этом месте.

**Блокируется:** ничем (можно начинать сразу)

**Статус:** ready-for-agent

**Решения (2026-09-16):**
- Термины глоссария: **Панель инструментов** (Toolbox) и **Группа инструментов** (Tool group). Не использовать «подблок», «карточка».
- Заполнение по рядам: при трёх элементах два сверху и один снизу.
- Группа Отменить/Повернуть/Копировать, у которой не было заголовка, называется «Правка».
- Заголовки переведены (английский и русский).

- [ ] Рефакторинг идёт первым, существующие тесты проходят без изменений
- [ ] Пять групп в порядке Инструменты, Цвета, Правка, Отражение, Прогресс по рядам, у каждой заголовок в левом верхнем углу
- [ ] Элементы идут слева направо максимум в два ряда по семь; группа из трёх элементов заметно уже группы цветов
- [ ] Текстовые/числовые элементы занимают целый ряд и не считаются в 14 мест
- [ ] Заголовки есть на обоих языках
- [ ] На ширине телефона панель помещается без горизонтальной прокрутки страницы
