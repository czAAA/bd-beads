# 37: Бисер схемы в шапке

**Что нужно сделать:** Схема плетётся из одной бисеринки, поэтому, пока схема открыта, в правом блоке шапки рядом с описанием текущей схемы показывается, какой бисер используется, например "TOHO Round 11/0". При переключении на другую схему он обновляется, а без открытой схемы исчезает.

**Блокируется:** ничем (можно начинать сразу)

**Статус:** ready-for-agent

**Решения (2026-09-16):**
- Бисер показывается только в шапке, не в списке сохранённых схем (сейчас он использует тот же текст описания схемы).
- Если бисер схемы не найден (например, свой бисер, удалённый в тикете 38, или загруженный файл), в шапке показывается нейтральное "неизвестный бисер", без ошибки и без сырого id.

- [ ] При открытой схеме в правом блоке шапки показывается её бисер (бренд, название, размер)
- [ ] При переключении схем бисер обновляется
- [ ] Без открытой схемы бисер не показывается
- [ ] Для схемы, чьего бисера нет в каталоге, показывается "неизвестный бисер" на обоих языках
- [ ] Список сохранённых схем не меняется
