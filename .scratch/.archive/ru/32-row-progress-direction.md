# 32: Переключение направления "Прогресса по рядам" между рядами и столбцами сетки

**Что нужно сделать:** Новая кнопка-значок в карточке "Прогресс по рядам", которая переключает, как идут ряды плетения по сетке: вдоль рядов сетки (по умолчанию, как сейчас) или вдоль её столбцов. Она нужна потому, что "Повернуть" (тикет 28) только поворачивает картинку: после поворота схемы вертикально ряды сетки на экране стоят вертикально, и "Прогресс по рядам" продолжал затемнять вертикальные полосы вместо рядов, которые теперь видны поперёк экрана. Пользователь попросил отдельную кнопку, а не привязку к "Повернуть", поэтому они независимы: "Повернуть" никогда не меняет направление прогресса, а переключение направления никогда не поворачивает картинку.

**Блокируется:** Ничем

**Статус:** done

**Решения (2026-09-16):**
- У каждого направления своя сохранённая позиция. Переключение на столбцы и обратно возвращает на тот же ряд, так что случайный клик не теряет место в плетении.
- В мозаике (Peyote) и кирпичном плетении (Brick) каждый второй ряд сдвинут на полбисеринки, поэтому столбец сетки идёт зигзагом. Прогресс по столбцам отмечается по бисеринкам, так что затемнение и рамка текущего ряда повторяют этот зигзаг.
- Тесты на трёх уровнях: доменные функции в `pattern.ts`, `PatternGrid` (какие бисеринки затемнены и выделены) и `App` (клики по карточке).

- [ ] В карточке "Прогресс по рядам" есть кнопка-значок направления с подсказкой `title` + `aria-label` на английском и русском, `aria-pressed`, пока ряды идут по столбцам, и значком, не похожим ни на один другой в панели
- [ ] Пока ряды идут по столбцам, счётчик считает столбцы (`Ряд 3 / 10` на схеме 10 столбцов × 20 рядов), а "Предыдущий ряд"/"Ряд готов" переходят по столбцам и останавливаются на первом и последнем
- [ ] Пока ряды идут по столбцам, бисеринки в столбцах до указателя затемнены, а текущий столбец обведён рамкой; ни один целый ряд сетки не получает оформление прогресса
- [ ] Ряды и столбцы помнят каждый свою позицию: переключение направления туда и обратно возвращает на тот ряд, где остановилось плетение
- [ ] Направление и обе позиции сохраняются вместе со схемой (localStorage и экспортированные файлы), а схемы, сохранённые до этого тикета, открываются с рядами вдоль рядов сетки
- [ ] Переключение направления не является шагом отмены, не трогает сетку и не меняет флаг поворота "Повернуть" (и поворот не меняет направление)
- [ ] Карточка "Прогресс по рядам" всегда остаётся в одну строку (переключатели, счётчик, кнопки шагов), на английском и русском, при любом направлении; если места в панели не хватает, вся карточка переносится на следующую строку панели, а не переносится внутри себя
- [ ] Существующее поведение "Прогресса по рядам" вдоль рядов сетки не меняется
