# 04: Настроить и задеплоить приложение на GitHub Pages

**Что нужно сделать:** Выяснить, можно ли разместить это приложение — клиентское SPA без бэкенда, см. [ADR 0001](../../../../docs/adr/0001-local-only-persistence.md) — на GitHub Pages, и если да, опубликовать его там. Нужна и первоначальная настройка (конфигурация сборки под хостинг в подпапке Pages), и повторяемый способ выкатывать дальнейшие изменения, а не разовая ручная загрузка.

**Блокируется:** ничем (можно начинать сразу)

**Статус:** ready-for-agent

- [x] Подтверждено, что GitHub Pages подходит под требования приложения (только статический хостинг, хранение в localStorage, без сервера); задокументированы найденные ограничения, если есть
- [x] Конфигурация сборки Vite (`base`, пути к ассетам) настроена так, чтобы собранное приложение корректно резолвило ассеты при раздаче с URL GitHub Pages, а не только с `/`
- [x] Есть повторяемый способ деплоя (например, GitHub Actions workflow или задокументированный скрипт `npm run deploy`), чтобы публиковать дальнейшие изменения без ручного копирования файлов
- [x] Приложение опубликовано и доступно по URL GitHub Pages
- [x] В README описан процесс деплоя и указана ссылка на живую версию
