# 42: Очистить всё

**Что нужно сделать:** Кнопка «Очистить всё» в группе Инструменты возвращает открытую схему к состоянию сразу после создания с тем же размером. По нажатию открывается модальное окно подтверждения в стиле приложения (Отмена / Очистить всё; Escape отменяет). После подтверждения все ячейки пустые, прогресс по рядам сброшен (выключен, указатели обоих направлений рядов на первом ряду), а название, размер, техника, бисер и поворот схемы сохраняются. Это один шаг отмены, и «Отменить» возвращает и закрашенную сетку, и прогресс по рядам.

**Блокируется:** 40

**Статус:** ready-for-agent

**Решения (2026-09-16):**
- Термин глоссария: **Очистить всё** (Delete all) — см. CONTEXT.md.
- В отличие от других команд рисования, игнорирует блокировку сплетённых рядов: сброс прогресса — часть действия.
- Подтверждение — модальное окно приложения, а не браузерный `confirm()`.
- Отмена расширяется ровно настолько, чтобы для этой команды восстанавливать прогресс по рядам вместе с сеткой.
- Отражение на неё не влияет.

- [ ] Кнопка «Очистить всё» есть в группе Инструменты
- [ ] По нажатию открывается подтверждение; Отмена или Escape закрывают его, схема не меняется
- [ ] После подтверждения все ячейки пустые, прогресс по рядам выключен, оба указателя на первом ряду
- [ ] Название, размер, техника, бисер и поворот не изменились
- [ ] Одно «Отменить» точно возвращает прежнюю сетку и прогресс, включая сплетённые ряды
- [ ] Надписи в окне и на кнопке переведены
