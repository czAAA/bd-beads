# 21: Перенести инструменты редактирования над холст

**Что нужно сделать:** Перенести выбор инструмента, палитру, кнопку отмены, управление отражением и прогресс по рядам из левой основной панели в панель над холстом — вторым горизонтальным рядом под уже существующим рядом "Новая схема"/управление масштабом. Каждая функциональная группа отображается как отдельная небольшая карточка в этом ряду, на фоне в виде точечной сетки (как блокнот). Когда схема открыта, левая основная панель больше ничего не показывает (форму новой схемы она сохраняет только тогда, когда ни одна схема не открыта). См. [ADR 0005](../../docs/adr/0005-tools-above-canvas.md).

**Блокируется:** Ничем

**Статус:** ready-for-agent

- [ ] Выбор инструмента, Палитра, Отмена, управление отражением и Прогресс по рядам отображаются в панели над холстом, а не в левой основной панели, пока схема открыта
- [ ] Эти элементы отображаются вторым рядом под существующим рядом "Новая схема"/масштаб
- [ ] Каждая функциональная группа (инструмент / палитра / отмена / отражение / прогресс по рядам) визуально выделена как отдельная небольшая карточка
- [ ] У ряда фон в виде точечной сетки (равномерно расставленные точки)
- [ ] Левая основная панель ничего не показывает, пока схема открыта (без заглушки "скоро появится")
- [ ] Левая основная панель по-прежнему показывает форму новой схемы, когда ни одна схема не открыта — без изменений
- [ ] Область холста занимает освободившееся место от свёрнутой левой панели
