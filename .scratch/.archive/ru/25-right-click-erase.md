# 25: Стирание правой кнопкой мыши, по текущему инструменту

**Что нужно сделать:** Клик правой кнопкой мыши по холсту стирает вместо закрашивания, используя выбранный на данный момент инструмент, чтобы определить "зерно" стирания: при Кисти — одна ячейка (или стирание линии протягиванием), при Заливке — стирание всей связной области одного цвета за один клик.

**Блокируется:** 22 (стирание при Кисти должно учитывать живое отражение, как и закрашивание)

**Статус:** ready-for-agent

- [ ] Клик правой кнопкой по ячейке при активном инструменте Кисть стирает эту ячейку (убирает цвет)
- [ ] Протягивание с зажатой правой кнопкой при инструменте Кисть стирает каждую ячейку по пути, аналогично протягиванию левой кнопкой при закрашивании (см. тикет 24)
- [ ] Клик правой кнопкой по ячейке при активном инструменте Заливка стирает всю связную область одного цвета, содержащую эту ячейку, за один клик
- [ ] Стандартное контекстное меню браузера больше не появляется при клике правой кнопкой по холсту
- [ ] Стирание правой кнопкой учитывает режим отражения так же, как закрашивание — стирание также стирает отражённую ячейку/ячейки, если включена ось отражения и активен инструмент Кисть
- [ ] Каждое действие стирания правой кнопкой (одна ячейка, протянутая линия или заливка) отменяется одним шагом undo
