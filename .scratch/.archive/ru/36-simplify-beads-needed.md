# 36: "Нужно бисера" показывает только цвет и количество

**Что нужно сделать:** "Нужно бисера" становится простым списком покупок для открытой схемы: одна строка на каждый использованный цвет, с образцом цвета и количеством бисеринок этого цвета, самые нужные сверху. Цвета, которыми ничего не нарисовано, не показываются. Привязка цвета к бисеру убирается целиком: схема плетётся из одной бисеринки (она показывается в шапке, тикет 37), поэтому привязывать каждый цвет к бисеру не нужно.

- Столбцы "Бисер", "Бисер по умолчанию" и "Эта схема" и их выпадающие списки убираются.
- Общие привязки цвета к бисеру по умолчанию больше не сохраняются, собственные привязки схемы тоже.
- Файлы схем больше не записывают привязки по умолчанию. Файлы, выгруженные до этого изменения, по-прежнему загружаются: это поле и привязки внутри схем игнорируются.
- Без открытой схемы показывается прежнее сообщение "откройте схему". Если схема открыта, но ничего не нарисовано, показывается короткая строка "пока ничего не нарисовано" вместо пустой таблицы.
- Нарисованный цвет, которого нет в палитре (из старого загруженного файла), по-прежнему показывается с образцом и количеством.

**Блокируется:** ничем (можно начинать сразу)

**Статус:** ready-for-agent

**Решения (2026-09-16):**
- Показываются только цвета с количеством от 1; строк с нулём нет.
- Привязка удаляется полностью, а не скрывается, вместе с сохранёнными данными и полем в файлах схем.
- Зафиксировано в ADR 0007 (уже написан, в ADR 0002 добавлена пометка): палитра остаётся отдельной от каталога бисера, но привязка цвета к бисеру убрана, потому что схема использует одну бисеринку.

- [ ] В "Нужно бисера" ровно два столбца: образец цвета и количество
- [ ] Показываются только цвета, нарисованные хотя бы раз, самые нужные сверху
- [ ] Новый цвет добавляет строку; стирание его последней бисеринки убирает строку
- [ ] В "Нужно бисера" нет выбора бисера и названий бисера
- [ ] Без открытой схемы показывается "откройте схему", на пустой схеме строка "пока ничего не нарисовано", на обоих языках
- [ ] Привязки по умолчанию и привязки схем больше не сохраняются, а оставшиеся старые данные не ломают загрузку
- [ ] Выгруженные файлы схемы и библиотеки не содержат привязок по умолчанию
- [ ] Файлы, выгруженные до изменения (с привязками), загружаются правильно
- [ ] Строки перевода, нужные только привязке, удалены из обоих языков
- [ ] Запись "Bead quantities" в CONTEXT.md больше не упоминает привязку и ссылается на ADR 0007, а не только на ADR 0002
