# 30: Карточка "Прогресс по рядам" — кнопки-значки с подсказкой при наведении, высота не больше, чем у "Палитры"

**Что нужно сделать:** Кнопки "Предыдущий ряд" и "Ряд готов" в карточке "Прогресс по рядам" становятся кнопками-значками с той же подсказкой при наведении/фокусе, что и значки "Отражения" из тикета 29 и уже существующие значки "Отменить"/"Повернуть" — связка `title` + `aria-label`, без нового механизма подсказок. Как и с "Отражением", это перестаёт вынуждать все карточки в ряду `.tool-strip` быть выше "Палитры", поскольку `align-items: stretch` растягивает каждую карточку по высоте самой высокой на этой строке.

**Статус:** done

- [ ] Кнопки "предыдущий ряд" и "следующий ряд" ("Ряд готов") отображаются как кнопки-значки, а не текстовые кнопки
- [ ] Два значка чётко различают "вернуться на ряд назад" и "отметить ряд готовым / перейти дальше", и визуально отличаются от значков "Отменить"/"Повернуть"/"Отражение"
- [ ] Наведение курсора или фокус с клавиатуры на любой значок показывает существующий текст кнопки (на английском/русском) в виде подсказки
- [ ] Программы чтения с экрана по-прежнему озвучивают тот же описательный текст через `aria-label`

- [ ] Высота отрисованной карточки "Прогресс по рядам" не превышает высоту карточки "Палитра", как на английском, так и на русском, при стандартной ширине окна
- [ ] Клик по значку по-прежнему выполняет то же перемещение по рядам, что и раньше — меняется только отображение, не поведение
- [ ] Существующие тесты для этих кнопок (testid `row-progress-previous` / `row-progress-next`) проходят без изменений
