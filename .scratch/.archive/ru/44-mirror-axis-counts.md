# 44: Число осей отражения по каждому направлению и видимые оси

**Что нужно сделать:** В группе Отражение два переключателя вкл/выкл заменяются двумя счётчиками — «Лево–право» и «Верх–низ», у каждого стрелки уменьшить/увеличить на один: от 0 (направление выключено) до числа ячеек в этом направлении минус один. N осей делят сетку на N+1 равных полос; рисование ячейки кистью закрашивает и её пару в каждой другой полосе, причём соседние полосы — зеркальные отражения друг друга (A | A′ | A). С одной осью всё работает точно как нынешнее отражение по центру. Пока хотя бы один счётчик больше 0, оси нарисованы на холсте очень тонкими, но хорошо заметными линиями, при любом инструменте.

Всё это закрыто флагом функции **расширенное отражение**, который вводит эта задача, — чтобы выключить её, если что-то пойдёт не так. При выключенном флаге группа Отражение и живое отражение остаются точно как сейчас: два переключателя вкл/выкл с отражением по центру сетки, без счётчиков осей и без линий осей. Флаг — переменная окружения на этапе сборки `VITE_RICH_MIRROR`: включён при локальной разработке, выключен в сборке для GitHub Pages.

**Блокируется:** 40

**Статус:** ready-for-agent

**Решения (2026-09-16):**
- См. **Mirror** в CONTEXT.md и пометку в ADR 0006.
- Неровное деление: ось может проходить через середину ячейки, которая тогда отражается сама в себя (как у нынешней центральной оси при нечётном размере); полосы как можно более равные.
- Верхний предел для направления — число ячеек минус один, чтобы с каждой стороны любой оси была хотя бы одна ячейка.
- Направления названы по тому, что видно на экране. Поворот схемы меняет два счётчика местами, так что «Лево–право» остаётся лево–правом на экране.
- Счётчики — настройка сеанса редактирования: не сохраняются со схемой, сбрасываются в 0 при переключении схемы.
- Каждый счётчик занимает в группе целый ряд и не считается в 14 мест (задача 40).
- Заливка и вставка по-прежнему не зависят от отражения; живое отражение работает для кисти (рисование и стирание), а подсветка при наведении показывает все парные ячейки.
- «Отразить текущее» пока работает как раньше, до задачи 46.
- Флаг включён, только если `VITE_RICH_MIRROR` равно ровно `true`; если переменной нет или значение другое — выключен, так что прод по умолчанию в безопасности. В репозиторий кладутся `.env` с `VITE_RICH_MIRROR=false` и `.env.development` с `VITE_RICH_MIRROR=true` (`npm run dev` работает в режиме development; `npm run build`, который использует workflow для Pages, — в production). Менять workflow деплоя не нужно.
- Флаг читается в одном месте (маленький модуль флагов функций), чтобы все задачи расширенного отражения (44–47) проверяли один и тот же переключатель, а тесты могли задавать любое значение.

- [ ] Каждый счётчик показывает значение; «уменьшить» недоступно на 0, «увеличить» — на числе ячеек минус один
- [ ] Оба счётчика 0: рисование меняет только саму ячейку, осей не видно
- [ ] Одна ось лево–право: отражение по вертикальному центру точно как раньше
- [ ] N осей: закрашенная ячейка закрашивает зеркальную пару в каждой полосе; стирание так же
- [ ] Заданы оба направления: пары покрывают все сочетания полос
- [ ] Оси видны тонкими линиями в нужных местах (на границах ячеек или через их середину) при любом инструменте
- [ ] Поворот меняет счётчики местами; переключение схемы сбрасывает оба в 0
- [ ] Работает для станка, мозаики (peyote) и кирпичного плетения
- [ ] При выключенном флаге группа Отражение показывает нынешние два переключателя и две кнопки «Отразить текущее», рисование отражается только по центру, линий осей нет — существующие тесты отражения проходят без изменений
- [ ] В `npm run dev` флаг включён, в сборке `npm run build` — выключен
- [ ] Тесты покрывают оба состояния флага
