# 29: Карточка "Отражение" — кнопки-значки с подсказкой при наведении, высота не больше, чем у "Палитры"

**Что нужно сделать:** Две кнопки "Отразить текущее" в карточке "Отражение" панели инструментов — сейчас это текстовые кнопки, переносящиеся на две строки на русском — становятся небольшими кнопками-значками, по тому же принципу, что уже используют "Отменить" и "Повернуть" в соседней карточке. При наведении курсора или фокусе с клавиатуры на значок появляется текущий текст кнопки ("Отразить текущее (по горизонтали)" / "(по вертикали)") в виде подсказки — через ту же связку `title` + `aria-label`, которую уже используют "Отменить"/"Повернуть", без нового механизма подсказок. Результат: поскольку `.tool-strip` растягивает все карточки в ряду по высоте самой высокой из них, уменьшение кнопок "Отражения" перестаёт вынуждать её саму и соседние карточки быть выше "Палитры".

**Блокируется:** Ничем

**Статус:** ready-for-agent

- [ ] Обе кнопки "Отразить текущее" отображаются как кнопки-значки, а не текстовые кнопки, в карточке "Отражение"
- [ ] Значки для горизонтали и вертикали визуально различимы между собой и со значками "Отменить"/"Повернуть", и читаются как "отразить по этой оси"
- [ ] Наведение курсора или фокус с клавиатуры на любой значок показывает существующий текст кнопки (на английском/русском) в виде подсказки
- [ ] Программы чтения с экрана по-прежнему озвучивают тот же описательный текст через `aria-label` (без изменений по сравнению с текущим текстом кнопок)
- [ ] Высота отрисованной карточки "Отражение" не превышает высоту карточки "Палитра", как на английском, так и на русском, при стандартной ширине окна
- [ ] Клик по значку по-прежнему выполняет то же действие отражения текущего состояния, что и раньше — меняется только отображение, не поведение
- [ ] Существующие тесты для этих кнопок (testid `mirror-current-horizontal` / `mirror-current-vertical`) проходят без изменений
