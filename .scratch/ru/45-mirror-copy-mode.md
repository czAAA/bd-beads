# 45: Режим копирования в отражении

**Что нужно сделать:** Один переключатель в группе Отражение включает режим копирования. Когда он включён, полосы повторяются в одну сторону (A | A | A), а не чередуются зеркально (A | A′ | A): закрашенная ячейка закрашивает ячейку на том же месте в каждой другой полосе, в обоих направлениях.

Часть расширенного отражения (флаг вводится в задаче 44): при выключенном `VITE_RICH_MIRROR` переключатель не показывается, отражение работает как сейчас.

**Блокируется:** 44

**Статус:** ready-for-agent

**Решения (2026-09-16):**
- Один переключатель на оба направления.
- Режим копирования — отдельный переключатель, а не следствие числа осей, чтобы одна ось по умолчанию оставалась настоящим отражением (см. пометку в ADR 0006).
- Настройка сеанса редактирования: не сохраняется, сбрасывается при переключении схемы, как и счётчики.
- Если оба счётчика 0, переключатель видимо ни на что не влияет.

- [ ] Переключатель показывает состояние вкл/выкл
- [ ] При включённом режиме и 2 осях лево–право закрашенная ячейка в первой полосе закрашивает ту же ячейку во второй и третьей полосах, без отражения
- [ ] Выключение возвращает зеркальные полосы
- [ ] Переключение схемы выключает режим
- [ ] Надпись переведена
- [ ] При выключенном флаге расширенного отражения переключатель режима копирования не отображается
