# 48: Заменить бисер — смена и пересчёт бисера схемы

**Что нужно сделать:** Рядом с местом, где показан текущий бисер схемы, появляется элемент управления «Заменить бисер». По клику предлагаются остальные встроенные варианты из каталога. Выбор одного открывает модальное окно подтверждения (в стиле приложения, а не браузерный `confirm()`) с описанием того, что изменится: новый размер сетки, то, что цвета будут пересчитаны под него, и то, что прогресс по рядам и отражение сбросятся. Отмена или Escape оставляют схему без изменений.

Подтверждение меняет бисер схемы и пересчитывает: физический размер схемы (в мм) остаётся неизменным, поэтому количество столбцов/рядов пересчитывается из размеров нового бисера по той же формуле, что использует тикет 01 при создании схемы. Существующие цвета переносятся на новую сетку методом пропорциональной передискретизации по ближайшей ячейке, а не обрезаются — это приближённо сохраняет тот же рисунок на новом разрешении. Прогресс по рядам выключается, оба указателя направления возвращаются на первый ряд, а счётчики осей отражения сбрасываются в 0 по обоим направлениям, поскольку оба параметра завязаны на сетку, которой может больше не существовать в прежнем виде. Всё вместе — смена бисера, пересчёт сетки, пересчёт цветов и оба сброса — один шаг отмены. Доступно как для закрашенных схем, так и для пустых.

**Блокируется:** Ничем (можно начинать сразу) — тикеты 36-39 уже реализованы, зафиксированный каталог из 3 видов бисера и модель «один бисер на схему» уже на месте

**Статус:** ready-for-agent

**Решения (2026-09-17):**
- Термин глоссария: **Заменить бисер** (Replace Bead) — см. CONTEXT.md и [ADR 0008](../docs/adr/0008-replace-bead-recalculates-grid.md).
- Физический размер остаётся неизменным; столбцы/ряды пересчитываются из размеров нового бисера через `computeGridDimensions` (тикет 01), а не наоборот.
- Существующие цвета пересчитываются пропорциональной передискретизацией по ближайшей ячейке — не обрезаются и не блокируются целиком.
- Прогресс по рядам сбрасывается на первый ряд без блокировок; счётчики осей отражения сбрасываются в 0 — см. дополнения к статьям CONTEXT.md «Прогресс по рядам» и «Отражение», добавленные этим тикетом.
- Один шаг отмены полностью восстанавливает схему в состоянии до замены (сетка, цвета, прогресс по рядам, оси отражения — вместе).
- Модальное окно подтверждения по образцу «Очистить всё» (тикет 42): в приложении, Отмена/Escape закрывают его чисто.
- Доступно независимо от того, закрашена ли схема — основной сценарий именно такой: схема, которую уже начали рисовать.
- Изначально планировалось после тикетов 36-39 (зафиксированный каталог из 3 видов бисера, переход на «один бисер на схему») — они уже реализованы, так что блокировки больше нет.
