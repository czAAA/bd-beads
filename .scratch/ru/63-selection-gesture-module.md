# 63: Вынести жест Выделения/Копирования/Вставки в отдельный модуль

**Что нужно сделать:** Весь жест инструмента Выделение — разметка Выделения, Копировать и Вставить (включая разрешение неоднозначности «клик или перетаскивание» при нажатии) — переезжает из оболочки приложения в одно место за небольшим интерфейсом, вызываемое только пока активен инструмент Выделение. Видимых изменений нет: та же рамка выделения, то же поведение Копировать/Вставить, тот же шаг отмены на вставку.

**Блокируется:** 62 — этот модуль (`useSelectionGesture`) читает счётчики осей и режим копирования Отражения из модуля, вынесенного в тикете 62, а не напрямую из оболочки приложения.

**Статус:** ready-for-agent

**Решения (2026-09-19):** — по итогам того же архитектурного обзора, что и тикет 62 (см. ADR 0013 про отклонённого кандидата)
- Выделение, буфер обмена, отслеживание нажатия и собственный предпросмотр наведения инструмента Выделение (что покажет наведённая ячейка при вставке) переезжают вместе.
- Вставка по-прежнему коммитит через существующий общий путь изменения сетки/отмены (тот же, что используют Заливка и «Отразить как есть»), а не через отдельную копию.
- Приоритет Escape и клика правой кнопкой над модальными окнами подтверждения и развёрнутой Группой инструментов остаётся в оболочке приложения, которая последним шагом вызывает отмену в этом модуле.
- Состояние Выделения/буфера обмена по-прежнему сбрасывается через существующую единую точку сброса оболочки приложения при смене Схемы.
- Модуль никогда не проверяет, какой инструмент активен — оболочка приложения сама решает, вызывать ли его вообще.
- Основания для этого кандидата подтвердились при проверке: тикеты 31, 49 и 50 каждый напрямую и существенно редактировали именно этот код.

- [ ] Выделение, буфер обмена, отслеживание нажатия и предпросмотр наведения инструмента Выделение находятся в одном модуле, а не в оболочке приложения
- [ ] Вставка по-прежнему коммитит одним шагом отмены через существующий общий путь
- [ ] Приоритет Escape/клика правой кнопкой над модальными окнами и развёрнутой Группой инструментов не изменился
- [ ] Выделение/буфер обмена по-прежнему сбрасываются при смене Схемы
- [ ] Входные данные Отражения (счётчики осей, режим копирования) приходят из модуля тикета 62
- [ ] Все существующие тесты Выделения/Копирования/Вставки проходят без изменений
- [ ] Новый файл тестов покрывает вынесенный модуль напрямую
