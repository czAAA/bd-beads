# 20: Разделить верхнюю панель на два блока

**Что нужно сделать:** Разделить верхнюю панель на два отдельных блока: тёмный блок на фоне цвета «ink» только с логотипом/названием "bd-beads", и блок на фоне aqua-island с текущей схемой + переключателем языка — вместо сегодняшней единой aqua-панели.

**Блокируется:** Ничем (можно начинать сразу)

**Статус:** ready-for-agent

- [ ] Верхняя панель отображается как два визуально отдельных блока с рамкой, а не один
- [ ] Левый блок содержит только заголовок "bd-beads"; фон — существующий тёмный цвет ink/cello
- [ ] Правый блок содержит текущую схему + переключатель языка; фон остаётся aqua-island (как сегодня)
- [ ] Новые цветовые токены не добавляются — оба блока используют существующие токены
- [ ] Стиль рамки/отступов соответствует существующим блокам приложения
