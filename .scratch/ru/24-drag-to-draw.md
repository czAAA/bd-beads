# 24: Рисование протягиванием кистью

**Что нужно сделать:** Нажатие и протягивание курсора с инструментом Кисть закрашивает каждую ячейку, через которую проходит курсор, а не только ту, на которой был клик — так мазок рисует непрерывную линию.

**Блокируется:** Ничем

**Статус:** ready-for-agent

- [ ] Нажатие кнопки мыши на ячейке с инструментом Кисть закрашивает её, как и сегодня
- [ ] Протягивание при зажатой кнопке закрашивает каждую ячейку, через которую проходит курсор по пути, без повторных кликов
- [ ] Отпускание кнопки мыши завершает мазок
- [ ] Весь протянутый мазок — один шаг undo, а не по шагу на ячейку
- [ ] Инструмент Заливка не затронут — остаётся только по клику
- [ ] При включённом отражении протягивание также отражает в реальном времени каждую ячейку по пути (см. тикет 22)
