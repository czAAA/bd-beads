# 62: Вынести состояние сессии Отражения в отдельный модуль

**Что нужно сделать:** Счётчики осей Отражения, режим копирования, состояние наведения, два производных предпросмотра (оси при эффективном значении во время наведения курсора и ячейки, которые перезапишет клик) и сама команда «Отразить как есть» переезжают из оболочки приложения в одно место за небольшим интерфейсом. Видимых изменений нет: те же элементы управления в Панели инструментов, те же линии осей, то же поведение отмены.

**Блокируется:** Ничем (можно начинать сразу)

**Статус:** ready-for-agent

**Решения (2026-09-19):** — по итогам архитектурного обзора (см. ADR 0013 про отклонённого кандидата из того же обзора)
- Счётчики осей, режим копирования, состояние наведения, оба предпросмотра и сама команда «Отразить как есть» переезжают вместе — не только пассивное состояние, поскольку «Отразить как есть» — это собственная команда Отражения над собственным состоянием Отражения.
- «Отразить как есть» по-прежнему коммитит через существующий общий путь изменения сетки/отмены (тот же, что использует Заливка), а не через отдельную копию.
- Ограничение счётчика осей по-прежнему учитывает текущий размер открытой Схемы.
- Состояние сессии Отражения по-прежнему сбрасывается при смене открытой Схемы через существующую единую точку сброса в оболочке приложения.
- Новый модуль (`useMirrorState`) отдаёт своё состояние счётчиков осей/режима копирования наружу, чтобы модуль из тикета 63 мог его читать, не зная о существовании этого модуля.
- Основания для этого кандидата подтвердились при проверке: четыре тикета подряд (44, 45, 46, 47) напрямую редактировали именно этот код — в отличие от отклонённого кандидата из того же обзора (ADR 0013).

- [ ] Счётчики осей, режим копирования, состояние наведения и оба предпросмотра находятся в одном модуле, а не в оболочке приложения
- [ ] «Отразить как есть» тоже находится там и по-прежнему коммитит одним шагом отмены через существующий общий путь
- [ ] Ограничение счётчика осей по-прежнему учитывает текущий размер открытой Схемы
- [ ] Состояние сессии Отражения по-прежнему сбрасывается при смене Схемы
- [ ] Все существующие тесты Отражения (rich-mirror, Панель инструментов, сетка, холст) проходят без изменений
- [ ] Новый файл тестов покрывает вынесенный модуль напрямую
