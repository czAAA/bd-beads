# 22: Отражение в реальном времени при рисовании

**Что нужно сделать:** Заменить отдельную команду "Применить отражение" на отражение в реальном времени при каждом мазке, привязанное к точной центральной оси сетки. Добавить две небольшие кнопки "Отразить текущее" (по одной на ось) для разовой синхронизации уже нарисованного, повторно используя старую эвристику "большей половины". См. [ADR 0006](../../docs/adr/0006-live-mirror-while-drawing.md).

**Блокируется:** Ничем (отражение уже реализовано по тикету 09; здесь меняется его поведение)

**Статус:** ready-for-agent

- [ ] Общий чекбокс "Отражение включено" убран; горизонтальный и вертикальный переключатели сами по себе управляют отражением (любой, оба или ни одного)
- [ ] Кнопка "Применить отражение" убрана
- [ ] Пока активен инструмент Кисть и включён переключатель оси, закрашивание ячейки закрашивает и её отражённую пару/пары — отражение вычисляется относительно точного центра сетки: 2 ячейки при одной оси, 4 при обеих
- [ ] Заливка не зависит от состояния отражения (переключатели отражения не меняют поведение заливки)
- [ ] Две новые кнопки, "Отразить текущее (горизонталь)" и "Отразить текущее (вертикаль)", всегда доступны и каждая выполняет разовое отражение уже нарисованного по своей оси, используя ту половину, где закрашено больше ячеек, как источник (сегодняшняя эвристика)
- [ ] Изменения сетки от отражения (и живое отражение при рисовании, и "Отразить текущее") отменяются одним шагом undo, как обычное закрашивание
